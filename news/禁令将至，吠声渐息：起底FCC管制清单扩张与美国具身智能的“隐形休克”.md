# **禁令将至，吠声渐息：起底FCC管制清单扩张与美国具身智能的“隐形休克”**

今天，美国联邦通信委员会（FCC）向机器人与人工智能行业投下了一枚监管重弹。在一个由白宫召集的跨部门机构的全力支持下，FCC正式更新了其“受管制清单”（Covered List），将境外生产的“先进机器人设备”——具体指移动双足人形机器人和四足机器人——以及联网逆变器纳入其中。

通过撤销对新机型的设备许可，FCC实际上叫停了下一代中国机器人的进口。虽然现有的机器人队列被免于追溯，但对于依赖高性价比中国硬件的美国研究实验室、初创企业和高校学术部门而言，他们正面临着一场无声的软硬件“冰封”。

这一行动的核心指向了一个激烈的冲突：**国家安全是否足以成为一种合理的监管税，哪怕它可能会重创美国在具身智能（Embodied AI）领域的领导地位？**

---

### 物理网联安全威胁：FCC为何出手？

与早期针对华为或中兴等特定企业的“受管制清单”条目不同，本次更新是类别性的。任何在“外国敌对国家”（主要是中国）生产的、搭载密集传感器的移动人形或四足机器人都在封禁之列。要理解其背后的原因，必须剖析现代足式系统的技术架构。

像宇树科技（Unitree）的Go2四足机器人或G1双足人形机器人，绝非仅仅是电机的组合，而是一个高度集成、具备移动能力且联网的传感器集合体。它们装载了3D激光雷达（例如宇树自主研发的360°x90°超广角激光雷达）、深度相机、麦克风阵列以及多核边缘计算单元（通常为NVIDIA Jetson Orin模块）。

Alias Robotics等安全公司的研究人员反复证实，这些平台在出厂时就存在严重的安全漏洞：

#### CVE-2025-35027：从BLE到Root权限的命令注入
一个代号为 CVE-2025-35027 的高危漏洞波及了包括Go2、G1、H1和B2在内的多款宇树机器人。该漏洞存在于处理通过机器人蓝牙低功耗（BLE）接口传输的Wi-Fi配置的初始化脚本 [wifi_setup.py](file:///usr/local/bin/wifi_setup.py) 中。

系统在 [configure_wifi](file:///usr/local/bin/wifi_setup.py#L12) 函数中，将参数传递给Shell执行上下文之前，未能对输入进行安全过滤：

```python
# wifi_setup.py 中受漏洞漏洞程序简化示意
def configure_wifi(ssid, password):
    # 缺乏对 ssid 的输入校验导致命令注入
    cmd = f"nmcli dev wifi connect '{ssid}' password '{password}'"
    subprocess.Popen(cmd, shell=True) # 直接调用 Shell 执行
```

处于蓝牙低功耗（BLE）覆盖范围内的攻击者，可以广播伪装成SSID的恶意载荷（例如 `' ; rm -rf /; #`），从而触发 [subprocess.Popen](file:///usr/lib/python3/dist-packages/subprocess.py) 中的漏洞，以Root权限执行任意命令，夺取执行器控制回路的完整物理控制权。

#### 数据外泄与加密缺陷
对宇树G1人形机器人的进一步审计表明，该机器人会维持与外部境外托管服务器的持续TCP隧道。执行器转矩极限、激光雷达空间点云以及麦克风阵列的原始音频，正通过未公开的套接字被源源不断地回传。

当安全团队试图分析其专有的配置加密（属于机器人 [control_sys](file:///usr/bin/control_sys) 中“FMX”系统的一部分）时，发现了硬编码的静态加密密钥 [fmx_key](file:///usr/bin/control_sys#L45)：

```c
// 在 control_sys 反编译中发现的硬编码静态密钥
static const uint8_t fmx_key[16] = { 0x3F, 0x9A, 0xBC, 0x12, 0xD4, 0x5E, 0x6F, 0x78, 0x90, 0xAB, 0xCD, 0xEF, 0x11, 0x22, 0x33, 0x44 };
```

这种安全防范上的懈怠，使得任何能够拦截网络流量的设备都可以轻松解密遥测数据，并直接向机器人的关节轨迹控制器注入恶意的控制数据包。

#### ROS 2 DDS漏洞
大多数研究性代码库都部署在ROS 2（机器人操作系统2）之上，并使用 Eclipse CycloneDDS 或 eProsima FastDDS 等中间件。默认情况下，ROS 2 节点通过未加密的 UDP 组播进行通信。在典型的学术实验室中，如果宇树机器人连接到共享的大学Wi-Fi，该网段内的任何用户都可以欺骗 ROS 2 的 Topic（话题）。

攻击者可以轻松向 `/actuator_commands` 话题发布大扭矩指令，绕过 [motion_control.py](file:///home/robot/src/motion_control.py) 中的高层安全防护，通过发布畸形的 [JointState](file:///opt/ros/humble/include/sensor_msgs/msg/joint_state.hpp) 载荷，导致机器人发生剧烈的自我毁灭或攻击周围人员。

### “科研税”的现实差价：1,600美元对决75,000美元

尽管监管逻辑十分清晰，但对于美国实验室而言，其市场连锁反应却是灾难性的。足式机器人研究依赖于硬件的快速迭代。此前，美国研究人员面临着两难选择：要么为昂贵且生态封闭的本土硬件买单，要么从零开始手工搭建定制系统。

而中国制造商通过将硬件“白菜价化”（Commoditizing），打破了这一市场格局：

*   **四足机器人的鸿沟：** 美国波士顿动力（Boston Dynamics）的Spot堪称工程杰作，但其起售价高达 **75,000美元**。相比之下，宇树Go2 Air的起售价仅为 **1,600美元**，而提供低底盘SDK接口和NVIDIA Jetson Orin边缘计算的科研级Go2 EDU，价格也仅在 **11,000至16,000美元**之间。
*   **人形机器人的阻壁：** Agility Robotics的Digit售价在 **250,000美元**以上，而 Figure 02 或特斯拉 Optimus 等平台根本不向开放性的学术研究市场销售。与此同时，宇树G1标准型双足人形机器人的售价仅为 **13,500至16,000美元**，即便功能更全、完全可编程的高端G1 EDU，售价也在 **43,900至73,900美元**之间。

买一台Spot的预算，足够让大学实验室采购一个由四台Go2 EDU和一台G1人形机器人组成的“编队”。而禁售新机型将锁死美国研究人员的硬件基准线。他们将被迫在老化、过时的上一代硬件上开发2026年的强化学习模型；而与此同时，欧洲和亚洲的同行们却能使用更新、更敏捷、更便宜的迭代硬件。

### 行业分裂：Eric Jang 怒怼游说集团

FCC的这一铁腕举措暴露了AI学者与美国本土硬件制造商之间巨大的鸿沟。

在X（原Twitter）和Reddit上，诸多知名机器人专家对该禁令表达了强烈谴责。1X Technologies前AI副总裁 **Eric Jang** 直言不讳：

> “一刀切地禁用硬件是一种短视的粗暴行径，它将彻底瘫痪美国的科研实验室。美国几乎所有主要大学的机器人实验室都在性价比极高的中国硬件上开发具身智能软件。封锁了硬件，就是封锁了软件的进步。我们需要的是严格的数据防外泄规则，而不是对物理电机和碳纤维的禁令。”

Agility Robotics的AI负责人 **Chris Paxton** 同样表达了忧虑，称这一政策举措“对美国科技行业极为不利”。Paxton指出，如果没有廉价且皮实的物理测试平台，AI软件的绝对优势将毫无意义：

> “我们希望美国AI能够引领全球，但AI需要物理躯体才能学习。如果我们的研究生买不起廉价的人形机器人平台来测试他们的神经网络，他们就会落后。你无法在仿真环境里跑完所有的物理强化学习，从虚拟到现实（Sim-to-Real）的迁移依然离不开实体机器人。”

与此相反，包括国际无人系统协会（AUVSI）在内的美国本土防务与自动化游说集团，则对这一限制措施以及背后的《保护美国免受敌对机器人支配法案》（GUARD Act）给予了全力支持。

支持者辩称，中国公司受益于巨额国家补贴，人为压低了价格，使得美国本土机器人产业基地根本无法生存。他们强调，在关键供应链中依赖境外硬件是地缘政治的定时炸弹，并指出了境外制造的电源逆变器和机器人中可能隐藏着“自毁开关（Kill Switches）”的隐患。

### 行政避风港：“条件性审批”

FCC并没有完全封死大门，而是留出了一个行政“钥匙孔”。根据新规，制造商可以申请“条件性审批”（Conditional Approval）以获得设备许可。

然而，准入门槛高得令人望而生畏：
1.  **提交申请：** 申请材料必须以机器可读的PDF格式发送至 `conditional-approvals@fcc.gov`（同时抄送给 FCC 的 Chris Smeenk，邮箱为 `chris.smeenk@fcc.gov`）。
2.  **审核机构：** 根据2025年9月5日的总统行政令授权，美国战争部（DoW，其在此行政令下使用的二级名称）负责审查先进机器人设备，而国土安全部（DHS）负责处理联网逆变器。
3.  **核心条款：** 为获得批准，申请人必须提交一份具有法律约束力的、明确具体时间表的《美国本土制造与回流计划》。该计划必须列出详细的资本支出、预期招聘人数，以及将组装和供应链转移至美国本土的路线图。

对于像宇树科技这样的初创公司来说，为了绕过管制清单而在美国建立数百万美元的制造工厂，在经济上完全是天方夜谭。对于美国的实验室来说，这意味着这一“逃生通道”基本上形同虚设。

### 结语

FCC将先进机器人设备列入“受管制清单”，是典型的网络安全博弈：它确实缓解了一个真实存在的远程劫持与间谍刺探隐患，但同时也对美国AI产业征收了极其沉重的“科研发展税”。

随着我们深入具身智能时代，谁能掌控双足控制与物理操作软件的霸权，谁就将主导下一次工业革命。通过掐断廉价硬件的输入通路，美国政府是在拿未来做赌注，赌本土硬件初创公司能以足够快的速度填补空白。如果赌输了，美国的AI开发者们可能会发现，自己写出了世界上最顶尖的控制软件，却找不到一台被允许进口的机器人来运行它。
