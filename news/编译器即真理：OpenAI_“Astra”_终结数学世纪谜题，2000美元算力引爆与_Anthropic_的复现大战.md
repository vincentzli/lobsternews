# 编译器即真理：OpenAI “Astra” 终结数学世纪谜题，2000美元算力引爆与 Anthropic 的复现大战

2026年8月1日，生成式模式匹配与机器可检查的形式化推理之间的界限彻底崩塌。OpenAI悄然宣布，其下一代推理模型 **Astra** 的内部版本已经成功生成了数学和计算机科学理论界10个最棘手开放问题的经验证解答。

与过去那些停留在纸面、等待同行评审的AI学术论文不同，OpenAI这次直接在GitHub上托管了一份长达249页的手稿，并附带了完整的、可经机器验证的 **Lean 4** 证书。通过将这些证明直接针对Lean的标准数学库（`mathlib`）进行编译，OpenAI绕过了AI科研中最大的顽疾——幻觉。数学要么是正确的，要么编译器就会抛出类型检查错误，这里没有灰色地带。

这一成果堪称里程碑。Astra不仅成功证明了**非苏菲克群（Non-sofic group）**的存在——这是自数学家米哈伊尔·格罗莫夫（Mikhail Gromov）于1999年提出该概念以来群论界一直悬而未决的谜题；它还构造了一个反例，证伪了算子代数领域长达46年的**康尼斯刚性猜想（Connes's rigidity conjecture）**。然而，硅谷当下最瞩目的焦点甚至不是数学发现本身，而是一场瞬时爆发的“复现战争”。在OpenAI发布声明的24小时内，Anthropic研究员、前哈佛青年学者利文特·阿尔珀杰（Levent Alpöge）在X.com上宣称，他已使用Anthropic商业化推理模型 **Claude Fable 5** 成功复现了Astra这10个证明中的5个。

这是一场关于AI如何重塑形式化验证前沿、数学发现背后的算力经济学，以及硅谷AI巨头与全球数学界之间暗流涌动的冲突史。

### 数学细节：解构Astra的10个史诗级证明

要理解Astra所取得的成就，必须深入剖析其生成的具体数学结构。这10个被攻克的难题横跨了群论、高维几何、量子复杂度与密码学。

#### 1. 显式构造非苏菲克群
自1999年以来，群论学家一直被一个问题困扰：是否所有可数离散群都是“苏菲克群”？即它们的乘法表是否能通过有限置换群进行渐进逼指。Astra通过显式构造一个反例终结了这一争议：**二元 Leavitt 代数 $L_{\mathbb{F}_2}(1,2)$ 上的 $9 \times 9$ 矩阵初等子群**。

为了证明其非苏菲克性，Astra的证明架构巧妙融合了 **Property-(T) 扩张器** 与 **Thompson群 $V$**。它证明了，任何试图在有限置换“实验室”中逼近该群局部乘法规则的尝试，都必然会在指定的汉明距离（Hamming distance）内违反群公理。通过中位数归一化与分量对齐，Astra证明了该群的局部关系极度刚性，以至于任何有限的模拟最终都会崩溃，从而确立了并非所有无限结构都可以被有限结构逼近的真理。

#### 2. 证伪康尼斯刚性猜想
法国数学家阿兰·康尼斯（Alain Connes）于1980年提出的刚性猜想认为，对于某些高度刚性的群——特别是无限共轭类（ICC）Property (T) 群——其群冯·诺依曼代数 $L(\Gamma)$ 是完全决定该群 $\Gamma$ 的唯一“指纹”。

Astra通过构造无穷多个两两非同构的 Property (T) 群，并证明它们能生成同构的群冯·诺依曼代数，直接推翻了这一猜想。这证明了两个截然不同的代数结构可以投射出完全相同的“分析阴影”，解决了算子代数领域这一悬宕46年的悬案。

#### 3. 球堆积与编码理论下界
在高维几何领域，Astra推导出了高维空间中球堆积密度的更紧致上界。这是自1978年以来该领域的首次重大解析突破，使上界进一步逼近了著名的 Cohn–Elkies 阈值。与此同时，该模型推导出了在给定最小距离下二进制编码最大容量的指数级改良界限，并给出了高维球面编码的匹配结果。

#### 4. 算术电路复杂度与密码学
在理论计算机科学方面，Astra推导出了使用算术电路计算永久项（Permanent）的新下界，证明了 $n^4 / \log n$ 阶的算术公式下界。它还证明了广义双人量子博弈的指数并行重复定理。针对格密码（Lattice Cryptography），Astra确立了最近向量问题（CVP）的多项式因子近似硬度，这直接夯实了后量子密码方案的安全参数。最后，该模型还顺手解决了保罗·埃尔德什（Paul Erdős）猜想清单中的三个具体开放问题（第146、180和183题）。

### Lean 4 验证流：彻底告别“幻觉”

历史上，数学界对AI生成的证明始终抱有强烈的怀疑态度，因为这些证明往往充斥着微妙的逻辑跳跃甚至是胡言乱语的幻觉。OpenAI之所以能赢得信任，是因为他们要求Astra直接用 **Lean 4** 这种函数式编程语言兼证明助手来输出推理。

该工作流设计极为严密：
1. **CoT蓝图生成**：模型首先生成证明的自然语言思维链（Chain-of-Thought）蓝图。
2. **形式化翻译**：模型尝试将步骤分明的数学断言翻译成 Lean 4 代码。
3. **交互式调试循环**：模型与 Lean 编译器实时交互。如果编译器拒绝某个策略（例如未能闭合证明目标或指出类型不匹配），模型会自动读取编译器报错并重新生成代码。
4. **人类协作者介入**：当模型卡在某些极端复杂的数学定义时，人类数学家会介入，协助定义自定义引理或从 `mathlib` 中导入复杂的外部包。

在这一体系中，Lean 4 扮演了“去信任化验证层”的角色。数学证明不再是等待疲惫的同行们花上六个月去评审的叙述性论文，而是一个软件项目。只要 Lean 编译器无报错通过，并且代码中没有包含代表未完备假设的 `sorry` 占位符，那么在数学上，这个证明就是绝对成立的。

### 算力成本拆解：2000美元的科学奇迹

OpenAI透露，生成这10个数学解决方案的算力总成本在 GPT-5.6 Sol API 费率下仅为 **2000美元** 左右。

为了直观理解这个数字，我们可以参考2026年初发布的 GPT-5.6 Sol 模型的定价：
* **输入 Token**：每100万 tokens 5.00美元
* **输出 Token**：每100万 tokens 30.00美元

假设在搜索过程中，输入与输出 Token 的比例为 3:1，2000美元的预算大约可以兑换 **1.78亿 tokens**（约1.33亿输入 tokens 和 4400万输出 tokens）。这代表了一次规模极其庞大的智能体搜索（Agentic Search）。Astra 绝非只是在预测下一个词，而是在执行庞大的思维树搜索，在 Lean 编译失败时回溯，并并行测试数千条逻辑路径。

仅仅花费2000美元——甚至低于一个博士后单月的生活津贴——OpenAI就买下了10个困扰了人类数十年之久的数学真理。

### 硅谷复现战：Anthropic的闪电反击

Astra的成果一经公布，便在硅谷引爆了竞争的战火。不到24小时，Anthropic资深研究员 Levent Alpöge 在X上发帖挑衅：

> “复现只花了24小时，我已经用 Fable 搞定了其中一半。虽然发布公告里没怎么讨论提示词（Prompting），但我的配置和之前发布单位距离猜想时类似：完全自主、通用提示词、不联网（加上防泄露的疑邻盗斧式防御）。”

Alpöge 的声明将整场舆论带向了另一个维度：如果现有的商业 API 只要配上“通用提示词”就能在一夜之间复制半数成果，那么 Astra 究竟是一项独创的推理架构突破，还是说，这只是一次由人类精心挑选了“适合AI解答”的题库所制造的虚假神话？

这场复现战的底气来自于 Alpöge 在2026年7月的另一项里程碑成就。当时，他利用 Claude Fable 5 证伪了困扰数学界87年之久的 **$n \ge 3$ 维雅可比猜想（Jacobian conjecture）**。阿尔珀杰透露，他是在观看世界杯决赛的间隙给 Fable 发送了提示词，让其构造一个紧凑的、仅216个字符的 $\mathbb{C}^3 \to \mathbb{C}^3$ 多项式映射：
$$\left((1+xy)^3 z + y^2 (1+xy) (4+3xy),\ y + 3 x (1+xy)^2 z + 3 x y^2 (4+3xy),\ 2 x - 3 x^2 y - x^3 z\right)$$
该映射的雅可比行列式恒为 $-2$，但却不具备全局可逆性（它将三个不同的输入映射到了同一个输出），从而在三维及以上维度证伪了雅可比猜想。

Alpöge 能如此高效地从 Fable 中榨取出如此深邃的数学结论，表明 OpenAI 未公开的内部模型与 Anthropic 已上线的 API 之间的技术鸿沟，远没有 OpenAI 的公关稿吹嘘得那么大。

### 社会学张力与《莱顿宣言》的抗争

AI对纯数学领域的快速入侵，在传统学术界引发了深层的焦虑。2026年6月2日，全球多位顶尖数学家联合起草并发布了《莱顿人工智能与数学宣言》（Leiden Declaration on Artificial Intelligence and Mathematics），该宣言迅速获得了国际数学联盟（IMU）的正式背书。

《莱顿宣言》警告了三大生存威胁：
1. **企业垄断风险**：商业AI实验室可能会主导数学研究的方向，只资助或研究那些能展示其模型能力的数学问题。
2. **同行评审贬值**：人类数学家将被AI生成的铺天盖地的论文所淹没，导致评审机制彻底瘫痪。
3. **学科自主性丧失**：数学研究可能会从人类追求精神理解的纯粹殿堂，退化为一种单纯为了编译 Lean 代码的软件工程体力活。

数学家们的态度分裂成了两个阵营。曾在这类问题上倾注了多年心血的菲尔兹奖得主蒂莫西·高尔斯（Timothy Gowers）对 Astra 的研究结果表达了强烈的不安：
> “这非常奇怪，甚至让人不太舒服……看到AI解决了自己一直在亲身攻克的难题，有一种深深的挫败感。”

与之相对，陶哲轩（Terence Tao）的态度则更为温和务实，他呼吁学界积极拥抱变化，将AI视为协作工具而非替代者：
> “我们必须重新审视我们的价值体系和工作方法……学会利用这些工具来增强人类对数学的探索深度。”

### 结语

我们已经跨入了“经验证AI推理”的全新纪元。通过将神经网络锚定在 Lean 4 这样的形式化证明编译器上，AI在形式科学领域的幻觉问题已被终结。但正如 Astra 与 Fable 之间闪电般的复现战所表明的那样，这种推理能力正在被迅速商品化。现在的竞争核心不再是制造一个“会思考”的模型，而是决定我们究竟要让它去思考什么。
