# 礼来二代KRAS抑制剂斩获FDA突破性认定：精准医疗的“降维打击”，能否攻破胰腺癌的物理高墙？

生物医药行业正经历着一场悄无声息的“编译器升级”。数十年来，KRAS等癌基因一直被贴上“不可成药”（undruggable）的标签——在传统的小分子药物面前，这类靶点表面如同涂了润滑油般光滑，且其GDP/GTP置换循环速度极快，根本无法形成稳定的分子结合。然而，2026年8月3日，美国食品药品监督管理局（FDA）授予礼来（Eli Lilly）第二代KRAS G12C抑制剂Olomorasib（LY3537982）“突破性疗法认定”（Breakthrough Therapy Designation），用于单药治疗既往接受过治疗的晚期KRAS G12C突变型胰腺癌患者。

这是精准医疗对抗“癌症之王”——胰腺导管腺癌（PDAC）漫长战争中的一座里程碑。历史上，胰腺癌患者的5年生存率一直低于12%，惨烈不堪。然而，整个生物医药生态圈却对此产生了极大的分化。正当礼来凭借高选择性的共价“外科手术式打击”高歌猛进时，Revolution Medicines也正为其广谱、多选择性的“RAS(ON)”抑制剂RMC-6236准备新药申请（NDA）——该药此前在2026年的ASCO年会上大放异彩。

如今，KRAS管线的竞争已经不仅仅是“能否打中靶标”的问题，而是演变为一场关于分子选择性、如何跨越胰腺癌间质的物理屏障、以及如何围剿肿瘤适应性耐药网络的综合博弈。正是这些难题，让PDAC长久以来成为靶向疗法的“终极坟墓”。

### 分子底座：Olomorasib与第一代共价阻断剂的化学交锋

要理解FDA为何为Olomorasib大开绿灯，必须审视其“亚纳摩尔级”的分子硬件。第一代KRAS G12C抑制剂——即安进（Amgen）的Sotorasib（Lumakras）和Mirati/百时美施贵宝（BMS）的Adagrasib（Krazati），开创了靶向KRAS非活性、GDP结合状态的先河，通过锁定其特定构象来阻止其与下游RAF激酶结合。然而，这批“开拓者”在临床上受制于分子亲和力不足，需要极高的给药剂量，这导致了频繁的脱靶毒性，尤其是转氨酶异常（3/4级AST/ALT升高）引发的严重肝毒性。

```
   [活性KRAS - GTP结合态] <=======> [非活性KRAS - GDP结合态]
          |                                     |
          | (促进下游信号传导)                  | (被Olomorasib锁定)
          v                                     v
     促进肿瘤生长                          下游通路被阻断
```

Olomorasib的设计重构了这些底层参数。临床前数据显示，在KRAS G12C突变肺癌细胞系（H358）中，Olomorasib抑制GTP结合态KRAS装载的半抑制浓度（IC50）仅为 **3.35 nM**。相比之下，第一代阻断剂的IC50明显偏高：Sotorasib为 **47.9 nM**，Adagrasib则高达 **89.9 nM**。

此外，在抑制MAPK通路关键下游效应因子磷酸化ERK（pERK）的实验中，Olomorasib的IC50达到了惊人的 **~0.65 nM**，而Sotorasib和Adagrasib则都在 **13–14 nM** 附近徘徊。

这种数量级上的效能提升，使得Olomorasib在极低的绝对暴露量下，即可实现超过90%的靶点占有率。这在临床上直接兑现为安全性的巨大跃升。安进的Sotorasib至今仍在艰难应对监管部门的审视（其完全批准的补充新药申请在2023年底因CodeBreaK 200验证性试验中的数据完整性及患者交叉用药问题被FDA拒绝）；与此形成鲜明对比的是，Olomorasib表现出极低的肝毒性，这意味着它能够轻松与其他疗法开展联合用药。

正如Reddit r/biotech板块上一位知名生物制药工程师所评价的：
> “化学结构不会撒谎。Sotorasib就像是初稿分子。用3 nM的细胞级IC50去敲击switch II口袋，而不是用48 nM，这意味着礼来可以在不破坏患者转氨酶指标的前提下，优化给药剂量。这才是真正的工程学胜利。”

### 胰腺癌高墙：为何PDAC是完全不同的“怪兽”？

在非小细胞肺癌（NSCLC）中靶向KRAS G12C相对容易（Olomorasib在此领域的首个突破性疗法认定是与Keytruda联合用药），因为肺部肿瘤血管丰富，间质密度适中。然而，胰腺导管腺癌（PDAC）却是一座物理与生理层面的双重坚固堡垒。

PDAC的典型特征是拥有极为致密的纤维增生性间质（Desmoplastic Stroma）——由胶原蛋白、活化的星状细胞和成纤维细胞构成的细胞外基质，这造成了极高的组织间液压。这层间质构成了物理屏障，压迫血管，使小分子药物极难渗透并达到杀伤肿瘤核心所需的治疗浓度。

即使药物侥幸突破了间质，也必须面对肿瘤顽固的自适应耐药。在胰腺癌中，一旦阻断KRAS G12C，会迅速引发上游受体酪氨酸激酶（RTK，尤其是 **EGFR**）负反馈机制的失效。这导致下游MAPK通路信号出现代偿性反弹——肿瘤细胞通过EGFR反馈激活野生型RAS蛋白，将信号传导链路强行“重定向”。

```
       EGFR（受反馈调节重新激活）
         |
         v
     野生型RAS（绕过G12C阻断）
         |
         v
     MAPK / ERK 信号反弹（肿瘤存活）
```

为了遏制这种“ERK反弹”，目前的临床试验越来越依赖垂直通路联合阻断策略。在LOXO-RAS-20001（NCT04956640）的I/II期研究中，礼来不仅评估了Olomorasib的单药疗效，还探索了它与EGFR抑制剂西妥昔单抗（Cetuximab）的联合疗法，旨在彻底封死肿瘤的逃逸路径。

### 显微镜下的疗效数据：LOXO-RAS-20001释放了什么信号？

FDA授予Olomorasib单药治疗PDAC突破性认定，直接动力源自LOXO-RAS-20001临床试验中释放的早期疗效信号。

在AACR年会上公布的早期剪影中，在12名接受过吉西他滨或FOLFIRINOX方案化疗后进展的、可评估的胰腺癌患者中，Olomorasib实现了 **42%的客观缓解率（ORR）**，疾病控制率（DCR）则稳定在 **81%至92%** 之间。

如果将这一数据与竞争对手在既往接受过治疗的胰腺癌患者中的历史数据进行横向对比，差距显而易见：
*   **Sotorasib (CodeBreaK 100):** ORR 为 **21.1%**
*   **Adagrasib (KRYSTAL-1):** ORR 为 **33.3%**
*   **Divarasib (罗氏/创基因):** ORR 约为 **36%**（处于一个小型泛实体瘤篮子研究队列中）

Olomorasib 42%的ORR无疑是一次飞跃。但在生物医药风投（VC）和二级市场投资人眼中，谨慎情绪依然笼罩着其商业天花板。

### 竞争格局：特异性“精密打击”VS广谱“RAS(ON)”

在硅谷和全球生物医药风投的核心圈，最激烈的战略争论在于：**突变特异性的G12C抑制剂在胰腺癌中是否已经过时？**

因为在所有胰腺癌患者中，KRAS G12C突变的发生率仅为 **1%到2%** 左右。相比下，KRAS G12D突变驱动了约40%的病例，G12V突变则占了近30%。这意味着，像Olomorasib这样的突变特异性药物只能覆盖极其小众的患者群体。

这正是Revolution Medicines（RevMed）及其明星药物 **RMC-6236 (daraxonrasib)** 试图颠覆的战场。与传统靶向特定突变、非活性GDP状态的分子不同，RMC-6236是一款分子胶，它直接锁定多款RAS变体（包括G12D、G12V、G12C等）处于活性的、GTP结合的“ON”状态。

在ASCO 2026年会上，Revolution Medicines公布了其在经治转移性胰腺癌患者中开展的III期临床试验（RASolute-302）结果。RMC-6236将中位总生存期（mOS）直接从化疗组的6.7个月几乎翻倍延长至 **13.2个月**（风险比 HR 为 0.40）。FDA已于2026年7月正式受理了RMC-6236的新药申请（NDA）。

正如著名生物医药投资人Brad Loncar在行业论坛上指出的：
> “礼来的Olomorasib确实拥有令人惊叹的化学结构，但从商业化和临床试验入组的角度来看，在胰腺癌中筛查出仅占1.5%突变率的患者，过程极其缓慢且昂贵。RevMed的pan-RAS路线很有可能吞噬整个市场，因为它能够覆盖其余90%目前几乎无药可治的KRAS突变胰腺癌患者。”

### 监管与未来展望

礼来正在全力利用FDA授予的“突破性疗法认定”来压缩审查周期，实现滚动递交并增加与FDA的沟通频次。鉴于Olomorasib在非小细胞肺癌一线治疗中（与Keytruda联用）已然斩获突破性认定，礼来的肿瘤战略路径非常清晰：利用该药极其优异的安全数据，将其打造为肿瘤免疫疗法及其他靶向药的“首选黄金搭档”，试图在安进Sotorasib折戟的战场上赢回失地。

对于携带KRAS G12C突变的胰腺癌患者而言，这一监管决议提供了一条强有力的精准治疗生命线。而对于整个生物医药市场来说，这更是一堂生动的经典教学课——它清晰地展示了下一代药物化学如何通过优化分子安全性，在竞争日趋白热化的靶向药红海中，为自己撕开一块极具含金量的生态领地。
