# 十亿美元的“遥操农场”：拆解XDOF、具身智能的数据高墙与物理世界争夺战

在结束隐形模式（Stealth Mode）并斩获7000万美元A轮融资仅仅三个月后，机器人数据基础设施初创公司 XDOF 已经骤然被推向了硅谷2026年最具攻击性的估值风暴中心。

凭借接近5000万美元的年化营收运行率（ARR Run-rate），以及涵盖了全球近二十家顶尖前沿AI实验室的客户名录，这家从加州大学伯克利分校（UC Berkeley）剥离出的硬核团队，正在敲定一轮估值高达12亿美元的B轮融资。本轮融资由乔·隆斯代尔（Joe Lonsdale）创立的8VC领投，Thrive Capital、Andreessen Horowitz（a16z）与Lux Capital持续跟投。

要理解为什么一家调度着实体遥操作工装夹具、定制机械臂与高频传感器数据流的公司能在极短时间内跻身十亿美元独角兽俱乐部，就必须直面眼下正在困扰整个具身智能（Embodied AI）领域的根本性危机：**物理数据之墙（Physical Data Wall）**。

### 物理学的瓶颈：Token 与运动学维度的代沟

大语言模型之所以能沿着平滑且可预测的“计算最优前沿”（Compute-Optimal Frontier）一路扩展，是因为它们吞噬了从开放互联网上免费抓取的超过15万亿个Token。Common Crawl、GitHub代码库、arXiv学术论文以及数字化的浩瀚书籍，为自监督预训练提供了一片边际成本近乎为零的肥沃数字公域。

但实体机器人没有这样的数字公域。物理世界没有可供索引的 DOM 树。

要教会一台人形机器人或双臂协作系统去折叠一件没有固定形状的衣物、将一根柔性电缆穿过狭窄机箱，或是从钱包里抽出一张信用卡，系统需要的是高频、多模态的感知运动轨迹（Sensorimotor Trajectories）。自回归大语言模型处理的是低延迟Token边界处的离散符号序列；而具身控制策略（Embodied Policy）必须同时吞下多角度连续视觉流、关节状态以及高维度的本体感觉反馈，并在 30 Hz 到 50 Hz 的超高频率下，预测连续的末端执行器速度或关节目标位置。

```
│ 边际成本：约 $0.000001 / Token       │   │ 单幕数据成本：$5.00 - $25.00 / Episode│
│ 模态：离散符号文本                    │   │ 模态：同步RGB-D + 关节扭矩 + 运动学  │
│ 采样频率：Token级离散延迟             │   │ 采样频率：30 Hz - 50 Hz 高频连续流   │
│ 扩展天花板：逐步逼近算力与公域极限    │   │ 扩展天花板：从第一天起就面临严重饥渴 │
└──────────────────────────────────────┘   └──────────────────────────────────────┘
```

过去，机器人学术界曾试图通过开源聚合来解决数据饥渴。Open X-Embodiment（RT-X）项目虽然在理念上极具开拓性，拼凑了跨越22种不同机器人形态的近百万条轨迹，但在实际工程落地中，RT-X反而彻底暴露出“弗兰肯斯坦式拼凑数据集”的致命缺陷：相机内参严重冲突、本体感觉缺乏统一标定、控制频率在 3 Hz 到 10 Hz 之间剧烈抖动，而且绝大多数数据充斥着在平整桌面上抓取硬质物体的简单半静态任务。

“具身智能不是撞上了数据墙，它是从诞生第一天起就死死盯着这堵墙，”旧金山一家顶级AI实验室的资深研究科学家坦言，“你不可能从YouTube视频里爬取到物理直觉。被动视频里没有动作标签，没有触觉反馈，没有扭矩动态，更没有闭环的反事实因果律。如果你不知道机械爪指尖到底施加了多少牛顿的力，视频对机器人来说就只是一层好看的壁纸。”

### ABC技术栈：将具身轨迹采集流水线工业化

这正是 XDOF 切入的生态位。XDOF 于2024年底由伯克利机器人专家 Philipp Wu（CEO）和 Fred Shentu（申屠，CTO）——也是广受赞誉的 GELLO 遥操作系统联合作者——携手前特斯拉资深车辆工程架构师 Nemo Jin（金，COO）共同创立。他们试图打造投资人眼中“物理世界的 Scale AI”。

该公司的科研根基在2026年6月伴随着 **ABC** 技术栈与 **ABC-130k** 数据集的开源而彻底公布，详见其里程碑式论文 *《Scalable Behavior Cloning with Open Data, Training, and Evaluation》*（arXiv:2606.27375）。该成果由加州大学伯克利分校、Amazon FAR、麻省理工学院（MIT）与卡内基梅隆大学（CMU）联袂打造，作者阵容包括 Pieter Abbeel、Jitendra Malik、Phillip Isola、Rocky Duan（段岩）以及 Angjoo Kanazawa 等机器人学与计算机视觉界的泰斗级学者。这代表着迄今为止全球最大规模的开源双臂遥操作语料库：

* **数据体量**：涵盖 **134,806 条高质量双臂操作轨迹**，累计长达 **3,553 小时** 的物理真机示范数据，横跨195种高复杂度任务（包括纸箱折叠、衣物整理、动态交接及精密机械插拔）。
* **硬件标准化工作站**：统一运行在 **YAM（"Yet Another Manipulator"）** 硬件平台上——这是一套采用无刷直流电机（BLDC）并由实时CAN总线驱动的双臂6自由度系统，配备柔顺平形夹爪。
* **遥操作交互界面**：基于运动学几何映射的 GELLO 从动控制器，人类操作员可以直接通过操纵主端“木偶”手柄来近乎零延迟地镜像驱动机械臂。
* **传感时钟对齐**：采用3路 30 Hz 同步相机采集——1个俯影视角第三人称全局相机，以及2个安装在手腕上的第一人称视角传感器（融合 Intel RealSense 与 Stereolabs ZED-X 双目立体视觉），笛卡尔空间标定精度达亚毫米级。
* **底层序列化封装**：将RGB-D流、关节编码器绝对状态、夹爪输出力矩与末端轨迹全部封装进 **Foxglove MCAP** 容器，确保分布式节点毫秒级时钟严格对齐。

#### 用操作员ID条件化破解多模态方差
在实体操作员流水线中，最大的隐性技术瓶颈在于“多操作员方差”（Multi-Operator Variance）。当15个不同的人类操作员完成折纸箱这一相同任务时，每个人在动作快慢、路径选择、以及中间抓取点姿态上都存在天壤之别。

在传统的行为克隆（Behavior Cloning, BC）框架下，直接把这批未经解耦的数据喂进神经网络，会导致严重的**灾难性模式均化（Catastrophic Mode Averaging）**。当模型面对“从左侧绕过障碍物”和“从右侧绕过”两种同样成立的演示数据时，基于均方误差（MSE）优化的策略往往会直接输出这两条路径的平均值——结果就是指挥机器人径直撞上面前的障碍物。

尽管当前的扩散变压器（Diffusion Transformers, DiT）与视觉-语言-动作（VLA）模型在多模态分布拟合上远优于传统的MLP架构，但杂乱的人类操作噪声依然会严重侵蚀策略的执行稳定性。XDOF与伯克利团队并没有粗暴地筛除数据，而是引入了 **Operator-ID Conditioning（操作员身份条件化）**。在模型预训练阶段，系统将每个操作员独特的身份嵌入向量（Embedding）拼接进状态观测空间中，促使神经网络自发地将个体的运动风格特异性与任务底层的物理执行逻辑解耦。在下游推理时，工程师只需指定最高水准操作员的风格向量进行条件引导，即可在保留整个数据集惊人规模的同时，完美规避模式坍塌。

#### 仿真信条：“算力即环境，环境即数据”
合成数据联盟的领军人物是英伟达具身智能研究负责人、GEAR团队主管范麟熙（Jim Fan）博士。Fan 一直旗帜鲜明地主张：依靠肉身人类去遥操作机械臂，从扩展法则的角度看根本就是一条走不通的死胡同。

在 AI Ascent 2026 峰会上，Fan 发表了一段震动业界的激辩演说：
> “请为遥操作默哀一分钟。它是我们在没有更好工具时的‘辅助轮’，但在物理扩展维度上它存在不可逾越的硬伤。它太慢了，极其昂贵，并且永远被锚死在人类真实的生物时钟上。具身智能终极的等式只有一个：算力即环境，环境即数据。终局绝不是去雇佣成千上万名人类提线木偶师，而是打造世界动作模型（World Action Models），利用像 Isaac Sim 这样以高于现实物理时钟一万倍速狂飙的高并行物理引擎。”

在英伟达 Isaac Lab 以及基于GPU并行加速的环境（如 Isaac Gym、HOVER）中，研究员只需在单台 DGX 系统上就能同时拉起4096个并行仿真的虚拟机器人。一位工程师吃个午餐的功夫，人形机器人策略就能在虚拟空间中刷完十年的奔跑平衡与障碍恢复训练。在刚体动力学、地形越野以及基础的接近-抓取任务上，结合域随机化（Domain Randomization）技术的 Sim2Real 迁移确实取得了令人惊叹的成绩。

#### 物理基底的反驳：非线性接触动力学的“诅咒”
然而，在常年与物理真机摸爬滚打的硬核机器人学者看来，仿真优先的教条主义完全脱离了非刚性物理学与材料形变的残酷现实。

“在你伸手触碰那些不是硬木块的东西之前，仿真模拟确实显得完美无缺。”UC Berkeley 副教授、前沿具身基座模型实验室 Physical Intelligence（Pi，$\pi_0$ 模型的缔造者）联合创始人谢尔盖·莱文（Sergey Levine）直言不讳地反驳道。

以莱文为代表的经验主义机器人专家强调，目前的物理引擎（无论 MuJoCo、PhysX 还是 FleX）底层全部高度依赖简化的数值解算器来逼近接触力学。而在现实世界中，算法会瞬间撞上物理学的三大暗礁：
1. **摩擦迟滞效应（Frictional Hysteresis）**：摩擦系数并不是静态常数，随着表面微观升温、材料磨损或瞬态滑移，摩擦特性处于高度非线性巨变中。
2. **可形变材质（Deformable Materials）**：纺织物、乱成一团的柔性电缆、软塑料、食物以及包装纸壳那不可预测的混沌运动学。
3. **微接触与机械卡滞（Micro-Contact and Jamming）**：在毫米乃至微米级公差下，将工业公母接口严丝合缝对准、或将歪斜螺丝拧入螺孔所激发的微观力学震颤。

当仿真环境中的机械手夹起一个软橡胶球时，物理引擎仅仅是在几何侵入深度的基础上计算一个虚拟的惩罚力；但在真实世界里，机械手指尖的硅胶垫会瞬间发生物理形变，表面摩擦力在不规则受压面上动态重新分布，毫秒级的微观振动直接决定了这个物体是会被稳稳抓起，还是从指缝间滑落。如果一个AI策略完全在纯粹的合成全息甲板（Holodeck）中训练，这些在虚拟世界被忽略的动力学细节，会在落地真机瞬间撕开一条致命的 Sim2Real 鸿沟。

正如 Pieter Abbeel 在发布 ABC 时所警示的那样：
> “仿真对于数据泛化和增强是不可或缺的工具，但唯有真实世界的物理遥操作，才能提供那层锚定现实的‘基底真值分布’，阻止基座模型去幻觉出根本不存在的伪物理规律。你永远不可能靠随机化参数，去凭空跨越那些你根本没能在数学上建立精确模型的摩擦定律。”

ABC 开源项目本身为这种混合折中路线提供了确凿的技术铁证：尽管团队在仿真环境中同样合成了400小时的遥操作数据（ABC-Sim），但那些完全由纯合成数据训练出来的策略，在面对真机折纸箱等高精度操作时全军覆没；模型若想在现实中具备可落地的成功率，必须与物理真机的 ABC-130k 真实演示轨迹进行联合训练（Co-training）。

### 数据中间商的商业账本：护城河能否抵御硬件主机厂？

XDOF 能够在三个月内从零爆发式跨越到近5000万美元的年化营收，本质上得益于当前机器人领域结构性的“淘金热套利”。无论是科技巨头（OpenAI、Google DeepMind、Anthropic、Meta FAIR），还是资金体量极度充沛的模型独角兽（Physical Intelligence、Skild AI），眼下都陷入了一场抢先炼出通用“机器人通用大脑”的超级军备竞赛。

然而，对于任何一家AI实验室来说，自建物理真机数据采集产线都是一个可怕的运营泥潭。如果一家实验室想要搜集5万条高质量双臂操作轨迹，它就必须：
* 采购、校准和维护动辄耗资数十万美元的高精度机械臂硬件；
* 搭建完全消除阴影死角、标准照度、安装公差严格对齐的多机位物理场地网络；
* 招募、培训并全天候轮班管理数十上百名人类遥操作员；
* 搭建一套超低延迟、能同时吞吐数TB无压缩传感器流且绝不丢帧的数据工程管道。

XDOF 将这些极其折磨人的脏活累活全盘封装，成功充当了行业外包的数据供应链基础设施：

#### 垂直整合巨头的降维阴影
尽管现金流跑得飞快，但持怀疑态度的硅谷风险投资人依然在叩问：面对垂直整合的机器人主机厂（OEM），XDOF 的这道数据护城河到底能撑多久？

* **特斯拉 Optimus**：在2025年年中副总裁米兰·科瓦奇（Milan Kovac）离职后，特斯拉正在全面淡化笨重的动作捕捉动捕服遥控，加速向完全基于纯视觉的模仿学习与人类视频端到端迁移。马斯克的底层算盘始终建立在制造业的规模效应上：一旦成千上万台 Optimus 人形机器人进驻弗里蒙特工厂与德州超级工厂，特斯拉庞大的自有汽车组装产线本身就会沦为一个完全自负盈亏、以零边际成本运转的超级数据农场，每天源源不断地泵出数以百万计的工业实战工时。
* **Figure AI**：创始人兼 CEO 布雷特·阿德考克（Brett Adcock）直接将整个商业赌注压在彻底的全自主性上，甚至在社交媒体上公开发难，痛斥真机遥操作是“充满欺骗性质的舞台杂耍”。尽管 Figure 近期也推出了“Index”零工众包平台，花钱雇佣全球普通人穿戴第一人称设备拍摄日常家庭任务视频，但阿德考克的战略非常纯粹：跳过所有第三方中间商，用第一方自主机队运行数据结合海量人类无标注视频，直接训练自家专属的 Helix 神经架构。

#### “中立国瑞士”的防守逻辑
既然如此，乔·隆斯代尔的 8VC 为什么还敢为 XDOF 押下12亿美元的巨注？

答案深藏于当下全球AI地缘商业格局的制衡体系中。那些试图在具身智能领域击败特斯拉和 Figure 的科技巨头与独立软件实验室，绝无可能坐等垂直硬件厂商良心发现把数据卖给自己——特斯拉永远不会把 Optimus 在产线上的高频控制日志授权给 Google DeepMind 或 OpenAI。

更关键的是，像 Skild AI 和 Physical Intelligence 这样的顶尖团队，野心在于打造**跨机械形态的通用控制策略（Cross-Embodiment Generalist Policies）**——即同一个神经网络大脑，既能控制一条 Franka 机械臂、一台 YAM 双臂工作站，也能驱动一台宇树四足机器人乃至副厂定制的五指高灵巧手。对于这些软件吞噬者而言，一家完全中立、硬件无关、能够源源不断吐出高标准、工业级清洗后的多形态运动学轨迹的独立数据商，就是这个时代最致命的战略咽喉。

当年 Scale AI 能够在各家前沿实验室相互猜忌、严防死守的夹缝中，靠标注多模态文本与图像数据铸就百亿美元帝国；如今的 XDOF，正是在具身物理世界中扮演着那个无可替代的“中立国瑞士”。

### 物理轨迹究竟能否催生机器人的“ChatGPT时刻”？

摆在整个行业面前最核心的悬念依然未解：即便物理演示数据的规模从13万条一路暴力狂飙到1000万条，就真的能给具身机器人带来通往通用智能的“ChatGPT时刻”吗？

机器人学界目前冷酷的数学共识是：**单靠模仿学习（Imitation Learning），绝无可能。**

纯粹行为克隆（Behavior Cloning）最根本的数学死穴，在于经典的**复合误差累积与协变量偏移（Compounding Error / Covariate Shift）**。当一个纯模仿策略被部署到复杂未知的现实世界时，机器人在执行路径中哪怕产生一丁点微小的单步执行误差，其物理状态就会偏离基准演示分布。在连续自回归输出中，这种预期误差随任务时域的拉长呈二次方爆炸：

$$\mathbb{E}[\text{Error}] \sim \mathcal{O}(\epsilon T^2)$$

其中 $\epsilon$ 为单步策略误差，$T$ 为任务的时间跨度。机器人一旦漂移进入此前从未见过的状态空间（例如抓取时发生打滑导致零件偏移了3毫米，或者未能一次性插准孔位），常规的行为克隆策略往往会陷入灾难性的僵死、机械性死循环或剧烈震颤。因为人类遥操作员在录制数据时几乎总是在完美顺畅地执行任务，他们极少在演示数据里展示“失误之后该如何自救与恢复”。

```
                        协变量偏移的死亡陷阱
                        
         理想轨迹（人类操作员演示的高概率分布）
         ─────────────────────────────────────────────────────► [任务成功]
               \
                \ 单步微小物理扰动 (ε)
                 \
                  ▼ 真实执行路径
                   \
                    \  误差累积呈二次方爆炸 ~ O(ε T²)
                     \
                      ▼ [从未探索过的未知状态空间]
                        （此处完全没有任何人类演示数据；
                         策略陷入概率盲区，机械臂死机、震荡或直接砸落）
```

将真机遥操作的时长无限堆砌，充其量只是在把那条“理想管道”的半径拓宽了一点点，它根本无法教会神经网络如何理解反事实因果，更教不会策略自主容错与恢复。

眼下，从伯克利、斯坦福到 Physical Intelligence 与 DeepMind，行业前沿正在逐渐形成一种类似于 AlphaGo 与现代深度推理模型的进化共识：

1. **底层物理真机预训练**：吞吐像 XDOF 的 ABC 这种高度标准化的大规模实体数据集，注入底层运动原语、双臂协同直觉以及跨本体的空间几何感知表征；
2. **高保真生成式仿真扩展**：引入英伟达 Isaac Lab 等物理环境进行大规模联合训练，以近乎无限且低成本的合成算力，打磨几何不变性与环境抗扰动韧性；
3. **闭环在线强化学习（Online RL）**：最终将机器人放养在可控的物理真机环境中，逼迫它们在不断的自我试错、自我崩溃与自我纠偏中，自主探索并涌现出强大的故障恢复边界。

XDOF 并没有在今天彻底终结具身通用智能的探索。但在这个物理交互 Token 极度匮乏的荒蛮年代，Philipp Wu、Fred Shentu 与 Nemo Jin 第一次为这个行业搭建起了一座工业级的物理现实开采工厂。

在迈向具身智能的淘金浪潮里，或许打造炫酷人形躯体的硬件厂商会赢尽聚光灯与掌声；但这家以每秒 30 次的高频脉冲、向全球前沿大脑日夜浇灌数以百万计严丝合缝物理轨迹的数据中间商，已经稳稳地锁死了这个机器人新纪元最为凶悍的一座收费站。
