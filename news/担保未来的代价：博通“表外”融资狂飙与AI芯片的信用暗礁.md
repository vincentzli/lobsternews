# 担保未来的代价：博通“表外”融资狂飙与AI芯片的信用暗礁

2026年8月中旬，博通公司（Broadcom Inc., AVGO）股价重挫8.11%。这场突如其来的暴跌令股票市场措手不及，但在债券交易场内，危机却似乎早已注定。几个月来，固定收益交易员一直在悄然推高博通债务的防范成本——自6月以来，其信用违约掉期（CDS）利差与债券收益率已拓宽了20至30个基点。这次大跌的直接导火索来自两方面：一是其新近收购的VMware vCenter平台被曝出存在致命的远程代码执行漏洞（CVE-2026-59310）；二是美银证券（Bank of America）分析师汤姆·库尔库鲁托（Tom Curcuruto）发布了一份令人警醒的研报，将博通的信用评级从“超配”（Overweight）下调至“标配”（Marketweight）。然而，在这双重打击之下，隐藏着一场更深层次的结构性交锋：CEO陈福阳（Hock Tan）正以何种方式为公司向定制化人工智能专用集成电路（ASIC）的激进转型提供资金？博通是否在以不为人知的巨大信用风险为代价，来维持其疯狂的增长？

这场争议的核心指向2026年6月启动的“AI XPV平台”（AI XPV Platform）。这是一个定制的表外融资工具，由博通与私募股权巨头阿波罗全球管理（Apollo Global Management）以及黑石集团（Blackstone）旗下的信贷与保险业务部合作搭建，旨在为博通定制XPU及网络管线的采购提供资金。根据协议，机构信贷基金出资购买这些硬件，并将其租给资金紧张的前沿AI实验室（其中最瞩目的合作方当属Anthropic）。首期项目是一笔高达350亿美元的资本承诺，用于支持Anthropic锁定1吉瓦的数据中心容量。通过租赁而非直接购买，Anthropic得以避免资产负债表过度膨胀，而博通则能立即录得硬件销售收入。

但美银的汤姆·库尔库鲁托警告称，这种模式背后隐藏着沉重的隐患。如果该XPV平台按计划在2028年前扩展至支持20吉瓦的算力，那么到2029年中期，它可能会累积高达3700亿美元的优先债务。为了让这些债务对黑石和阿波罗产生足够的吸引力，博通同意提供“残值担保”（Residual Value Guarantees, RVG），为租赁义务提供兜底。在首期350亿美元的融资中，博通披露的最大风险敞口为290亿美元。而在美银最坏情况的压力测试下，随着平台规模的扩大，博通在整个项目中的潜在损失敞口可能高达420亿美元。

在社交媒体上，这次信用评级下调激起了注重增长的股票投资者与规避风险的债券持有人之间的激烈交锋。Fintwit（金融推特）上的一位多头评论道：“AVGO（博通）简直就是在印钞。EBITDA高达152.4亿美元（利润率69%），第三季度AI芯片收入指引有望达到160亿美元。美银的降级是典型的债务分析师‘只见树木不见森林’。这3700亿美元的债务属于表外，且有阿波罗和黑石背书。博通在Anthropic这一期项目上的最大风险敞口被锁定在290亿美元。这完全是恐慌性买入的良机。”

相反，Reddit论坛r/stocks板块中一位持怀疑态度的网民反驳道：“大家都忽视了这里的风险。如果Anthropic没能做大规模，或者OpenAI放弃了定制芯片，会发生什么？博通的残值担保（RVG）意味着，如果这些定制XPU被淘汰，博通就得承担全部损失。定制ASIC芯片根本没有二手市场。这是一个巨大的隐形信用风险，随时可能引爆他们A-的信用评级。”

这场争论之所以戳中博通的痛处，是因为在2023年11月以690亿美元巨资收购VMware之后，博通传统资产负债表上的杠杆率已经居高不下。根据博通2026年6月3日发布的第二财季财报，公司总负债高达649.1亿美元，而持有的现金及现金等价物仅为196.3亿美元。当初收购VMware，本是为了构筑高毛利、经常性软件收入的“堡垒”，以此对冲芯片业务的周期性风险。在2026财年第二季度，博通创下了221.9亿美元的季度总营收历史新高，同比增长48%，调整后EBITDA达152.4亿美元。然而，其产品结构向低毛利定制化AI芯片的倾斜，已经开始压缩盈利空间。第二季度博通毛利率降至77.1%，同比收窄230个基点。随着博通指引第三财季AI半导体收入加速至160.0亿美元（占29.4亿美元总营收指引的大半），毛利率预计将面临进一步稀释，因为定制ASIC芯片的毛利率通常仅在65%至70%之间，远低于VMware约93%的软件业务毛利率。

毛利率的压缩，使得博通在面对任何业务波动时都变得极其脆弱。而就在此时，VMware偏偏开始亮起红灯。2026年7月29日，博通发布安全公告VMSA-2026-0006.1，披露了CVE-2026-59310漏洞——这是VMware vCenter Server Syslog中一个CVSS评分高达9.8的致命目录遍历漏洞，允许未经授权的攻击者绕过安全层并执行任意代码。到了8月3日，安全研究机构QUIRSO报告称，受国家支持的黑客正在积极利用该漏洞，通过目录遍历缺陷安装定时任务（cron jobs）并植入`reverse_ssh`后门，以建立持久的命令与控制连接。目前，已在47个国家检测到受害系统，其中德国和美国受灾最为严重。

这一软件安全漏洞的爆发，让原本就关系紧张的客户群怨声载道。在收购VMware后，陈福阳强力推行订阅制转型，部分客户的授权费暴涨了300%至500%，同时停售了永久授权。在Reddit的r/sysadmin论坛上，该安全漏洞成了声讨博通客户支持服务模式的集火点：“系统管理员们正因为CVE-2026-59310忙得焦头烂额。vCenter Syslog中一个评分为9.8、且被黑客疯狂利用来植入反向SSH后门的远程代码执行漏洞。博通之前乱涨VMware授权费已经惹毛了所有人，现在他们的支持门户网站还故意设卡，让没有购买高级支持服务的用户很难拿到补丁。这简直是场彻底的灾难。”

如果企业客户因为安全漏洞和价格暴涨而加速流失，博通的造血能力就可能在其表外承诺呈滚雪球式增长时出现滑坡。评级机构对此正虎视眈眈。尽管标普全球评级（S&P Global Ratings）曾在2025年9月将博通的发行人信用评级上调至“A-”，展望为稳定，穆迪（Moody's）也将其评级调升至“A3”；但两家机构均已发出警告，表外担保在评估时将被视为“类债务义务”。在特朗普政府的财政部长斯科特·贝森特（Scott Bessent）与美联储主席凯文·沃什（Kevin Warsh）的领导下，宏观信用环境对企业杠杆率（尤其是高增长科技领域）依旧保持着极高的敏感度。一旦标普或穆迪决定将XPV平台的债务并入博通的资产负债表，博通的各项信用指标将迅速恶化。

说到底，博通当下的张力在于短期需求叙事与长期结构性风险之间的博弈。定制化AI芯片市场正在呈指数级增长，但通过为客户的算力基础设施租赁进行债务兜底，博通实际上扮演了AI算力领域“次贷发放者”的角色。一旦Anthropic或其他承租方发生违约，或者在瞬息万变的技术迭代中这些专用芯片被淘汰，博通手中将只剩下数千亿美元无人问津的、高度专用且流动性极差的硬件。目前，陈福阳依然在赌这场AI狂欢是永恒的。但随着债券利差的走宽以及安全漏洞不断侵蚀VMware的软件护城河，资本市场已经开始在定价中反映这一可能性——陈福阳引以为傲的财技，这次或许终于碰到了对手。
