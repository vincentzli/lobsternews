# Hot Chips 2026 上的 ASIC 终极决战：OpenAI “Jalapeño” 与 Cerebras 3D 堆叠 CS-6 联手瓦解“英伟达税”

加州库比蒂诺——Hot Chips 2026 研讨会现场的气氛近乎沸腾。多年来，芯片行业一直遵循着一个不容挑战的铁律：英伟达（NVIDIA）定义了 AI 算力的天花板。但在今年，一场结构性的剧变发生了。随着 [DeepSeek R1](https://github.com/deepseek-ai/DeepSeek-R1) 和 OpenAI GPT-OSS 120B 等前沿大模型将计算负载的瓶颈从“模型训练”彻底推向“高强度、多步骤的 Agent 智能体推理”，整个行业正在撞上一堵难以逾越的硬墙：内存带宽。

本届研讨会的绝对主角——OpenAI 首次披露的自研推理 ASIC“Jalapeño”（哈拉帕辣椒），以及 Cerebras Systems 激进的晶圆级芯片路线图“CS-6”，无一不在宣告：行业正在抛弃通用 GPU，转向从零设计的专属芯片，以彻底解决内存带宽危机。

### OpenAI Jalapeño：9 个月的 Codex 研发奇迹

最受瞩目的技术披露来自 OpenAI。他们首次公开了第一代自研推理处理器 Jalapeño。这款由 OpenAI 联合博通（Broadcom）与天弘科技（Celestica）深度隐秘研发的芯片，采用台积电 N3P 工艺，功耗（TDP）为 700W。其最大亮点是搭载了高达 216 GB 的 HBM4 内存，带来了前所未有的 15.4 TB/s 超高内存带宽。

```
+--------------------------------------------------------+
|                    JALAPEÑO ASIC 架构                  |
|   台积电 N3P | 700W TDP | 216 GB HBM4 | 15.4 TB/s 带宽   |
+--------------------------------------------------------+
|   [ HBM4 ]       [ NUMA 空间计算架构 ]       [ HBM4 ]   |
|   108 GB  <=====>   216x 自定义张量核心   <=====> 108 GB   |
|  7.7 TB/s          (原生支持 MXFP4/MXFP8)       7.7 TB/s   |
+--------------------------------------------------------+
```

震惊 Hot Chips 观众的不仅是硬件规格，更是其惊人的交付速度。OpenAI 仅用了 9 个月就完成了从初始 RTL（寄存器传输级）设计到流片（Tape-out）的跨越（从组建团队到流片总共历时 16 个月）。这一奇迹的幕后推手是 OpenAI 自己的 Codex 模型，它被用于自动生成 Verilog 代码、自动化版图验证以及优化自定义执行算子（Kernels）。

在运行 GPT-OSS 120B 和 DeepSeek R1 的权威测试集 InferenceX 公开基准测试中，与英伟达最先进的 GB200 和 GB300 系统相比，Jalapeño 展现出了高达 1.9 倍的能效比提升（每千瓦时完成的 AI 工作量），以及高达 3.6 倍的端到端延迟降低。

SemiAnalysis 首席分析师 Dylan Patel 对此突破评价道：
> “第一代自研 ASIC 就能与甚至超越像英伟达这样的行业巨头，这在芯片历史上是极其罕见的。其核心秘诀在于极端的软硬件协同设计。当你同时掌控了模型架构、编译器和底层芯片时，你就能彻底剥离掉那些困扰通用 GPU 的冗余开销。”

Jalapeño 采用的是 NUMA 型的空间计算架构，原生支持开放微缩（Open Microscaling, MX）规范，特别是 MXFP8 和 MXFP4 数值格式。这在保持模型精度的同时，将计算精度要求降到了最低，从而让 Jalapeño 能够以极低的内存占用运行前沿大模型。

### Cerebras CS-6：以 3D 堆叠跨越“内存墙”

相比 OpenAI 专注于机架级 ASIC 的集成，Cerebras Systems 则将晶圆级（Wafer-scale）工程推向了逻辑终点。在 Hot Chips 上，Cerebras 公布了其下一代系统 CS-6 的路线图。

从历史上看，Cerebras 的晶圆级引擎（WSE）通过完全依赖超高速片上 SRAM 绕过了内存瓶颈。这虽然实现了每秒数 PB 级的带宽，但容量受限（WSE-3 仅有 44GB SRAM）。对于万亿参数模型，仅靠 SRAM 的架构必须将多块晶圆组成集群，这不可避免地引入了网络通信延迟。

CS-6 通过在晶圆级引擎上直接 3D 堆叠 DRAM 解决了这一容量上限。通过硅通孔（TSV）技术，DRAM 晶圆被直接叠放在逻辑与 SRAM 层之上。这使得 Cerebras 在保持其招牌的超低延迟织物（Fabric）局部性的同时，将内存容量提升了数个数量级。

```
+------------------------------------------+
|            3D 堆叠 DRAM 芯片层            |
+------------------------------------------+
|  ||||||   TSV (硅通孔)                   |
+------------------------------------------+
|       晶圆级逻辑与 SRAM 引擎 (WSE)         |
+------------------------------------------+
```

Cerebras 首席执行官 Andrew Feldman 解释了这一设计理念：
> “传统的 GPU 集群正陷入架构的死胡同。它们在板卡和交换机之间传输数据时，浪费了大量的功耗并带来了高延迟。而通过将内存直接堆叠在晶圆上，我们保持了数据与计算单元的物理近邻性。速度是 AI 时代的核心硬通货，而决定下一阶段胜负的将是基础设施的执行效率，而非仅仅是模型的智能程度。”

### 决战前沿：Prefill 与 Decode 分离以及解耦推理架构

Hot Chips 2026 的底层技术主线是“解耦推理（Disaggregated Inference）”。传统上，大语言模型（LLM）推理将 Prefill（预填充，算力受限，负责处理 Prompt）和 Decode（解码，内存带宽受限，负责自回归生成 Token）放在同一块芯片上运行，这导致了极低的硬件利用率。

行业正在加速走向这两类负载的物理分离。Prefill 被分流至高计算密度的集群，而 Decode 则被路由至经过内存带宽优化的硬件。

值得注意的是，OpenAI 在 Jalapeño 上走了一条独特的技术路线，采用了三阶段执行模型：
1. **Prefill（预填充）阶段**：高计算密度的处理，用于构建 KV 缓存（Key-Value Cache）。
2. **Drafting（草稿）阶段**：低延迟敏感的生成，使用投机采样（Speculative Decoding）。
3. **Verification（验证）阶段**：受内存带宽限制的计算，对草稿 Token 进行并行验证。

为了支持这种三阶段模型所需的海量 KV 缓存传输，OpenAI 与天弘科技（Celestica）共同设计了机架级的 Pod 配置。利用博通 Tomahawk 6 以太网交换芯片（拥有惊人的 102.4 Tbps 交换容量和多达 128 个 800GbE 端口），该系统可以在 16 个机架组成的 Pod 中扩展多达 2,048 颗 ASIC。这实现了芯片间近乎即时的 KV 缓存迁移，使整个机架本身成为了基础计算单元。

### 颠覆英伟达的垄断帝国

AI 的商业化逻辑正迎来临界点。对于消费级规模的应用而言，使用英伟达 H100 或 Blackwell 系列芯片运行万亿参数模型的经济成本已经高到无法承受。通过自研编译器绕过英伟达的软件生态护城河（CUDA），OpenAI 和 Cerebras 正在证明：垂直整合是让 Agent 智能体 AI 实现商业化落地的唯一出路。

OpenAI 首席执行官山姆·奥特曼（Sam Altman）近期指出：
> “软硬件协同设计是让 Agent 计算在经济上可行的唯一路径。如果不去控制每一美分的成本，我们根本无法在通用芯片上运行下一代模型。如果我们想让 Agent AI 无处不在，我们就必须在晶体管层级上控制单位经济学成本。”

英伟达最坚固的护城河一直是软件。但当客户只需要运行一套专属的软件栈时，CUDA 就不再是无法逾越的壁垒。Jalapeño 和 CS-6 的出现证明，当顶尖软件公司开始下场定义自己的芯片时，英伟达暴利的空间将是首当其冲被挤压的对象。
