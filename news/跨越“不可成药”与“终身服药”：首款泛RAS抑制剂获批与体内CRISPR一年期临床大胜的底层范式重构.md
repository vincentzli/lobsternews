# 跨越“不可成药”与“终身服药”：首款泛RAS抑制剂获批与体内CRISPR一年期临床大胜的底层范式重构

四十年来，肿瘤分子生物学始终被挡在一道名为 RAS 超家族的铁壁之前。这一突变驱动了人类约四分之一的恶性肿瘤，在致死率极高的胰腺导管腺癌（PDAC）中突变率更是超过 90%，却因其对 GTP 具备亚纳摩尔级的超高亲和力，加之其球状三级结构表面极为平坦、缺乏深层变构口袋，一直被传统药物化学界判定为“不可成药”（undruggable）。与此同时，在基因医学领域，体细胞体内（in vivo）基因编辑的终极梦想，也长期受制于递送动力学瓶颈、瞬时酶暴露窗口以及长期有效性持久度的严苛考验。

这一漫长的僵局在本周被两座里程碑式的临床进展同时打破：美国 FDA 加速批准了首款真正的泛 RAS 抑制剂 Daraxonrasib（商品名 Rasonque，由 Revolution Medicines 开发）；同周，《新英格兰医学杂志》（NEJM）刊登了 CRISPR Therapeutics 旗下靶向 *ANGPTL3* 的体内 CRISPR-Cas9 脂质纳米颗粒（LNP）疗法 CTX310 的 12 个月一期临床持久性数据。

这两项突破标志着生物医药底层工程架构的根本性跃迁：小分子药物正在进化为能够操控多状态蛋白质复合体的动态大分子胶；而基因治疗则正式跨越了自体外（ex vivo）罕见病细胞疗法，迈向面向大众慢性疾病、一针即可实现体内代谢终身重编程的全新纪元。

### 第一部分：Daraxonrasib 与泛 RAS 的生物物理学攻坚

第一代 KRAS 抑制剂（如 Sotorasib 与 Adagrasib）的核心局限在于极其狭窄的等位基因特异性。它们依赖于与 KRAS G12C 突变中的半胱氨酸残基发生共价结合，从而将蛋白质锁定在无活性的 GDP 结合态（OFF 态）。然而在胰腺癌中，G12C 突变所占比例不足 2%，绝大多数 PDAC 患者携带的是 G12D（约 40%）或 G12V（约 30%）突变——这些突变体缺乏反应性半胱氨酸巯基，且大部分时间顽固地停留在 GTP 结合的活化构象（ON 态）。

Daraxonrasib（RMC-6236）通过分子伴侣介导的“三元复合物抑制剂”（Tri-complex Inhibitor）机制绕过了这一生物物理路障：

```
[ Daraxonrasib ] + [ 亲环素 A (Cyclophilin A / CypA) ]
                           │
                           ▼
               [ 二元复合物：药物-CypA ]
                           │
                           ▼ （精准贴合活性效应区开关环）
  [ 三元复合物：CypA · Daraxonrasib · RAS (ON/OFF 态) ]
                           │
                           ▼
          [ 空间位阻物理阻断下游 RAF / PI3K 信号级联 ]
```

Daraxonrasib 放弃了在裸露 RAS 表面寻找不存在的深口袋，而是作为一种非共价分子胶发挥作用。它以亚纳摩尔级的亲和力招募细胞内高丰度的内源性分子伴侣蛋白——亲环素 A（CypA / PPIA）。所形成的“药物–CypA”二元复合物构建了一个全新的人工结合界面（neo-surface），精准对接 RAS 的 Switch-I 与 Switch-II 开关环。

这一巨大的三元复合物在空间上形成了巨大的位阻，直接物理阻断了 RAS 与其下游效应蛋白的对接——即阻断了 MAPK 通路中的 RAF 激酶和 AKT 通路中的 PI3K。更具决定性意义的是，由于 CypA 识别的是跨越活性态（GTP 结合）与非活性态（GDP 结合）的高度保守结构基序，Daraxonrasib 不仅能强效抑制各类突变体（G12D、G12V、G12R、G13X、Q61X），同时对野生型 KRAS、NRAS 和 HRAS 均具备广谱抑制活性。

#### 临床验证：关键三期 RASolute 302 试验
在针对既往接受过治疗的转移性胰腺导管腺癌（PDAC）患者的关键三期 RASolute 302 试验（NCT06625320）中：
* **总生存期（OS）：** Daraxonrasib 组中位 OS 达到 **13.2 个月**，而研究者选择的标准化疗对照组仅为 **6.7 个月**（风险比 [HR] = 0.40；$p < 0.0001$），实现了生存期的翻倍。
* **无进展生存期（PFS）：** 中位 PFS 达到 **7.2 个月** vs 化疗组 **3.6 个月**（HR = 0.49；$p < 0.0001$）。
* **客观缓解率（ORR）：** Daraxonrasib 组为 **30%**，对照组仅为 **11%**。
* **耐受性表现：** Daraxonrasib 组因治疗相关不良事件（TRAE）导致的停药率仅为 **1.2%**，而化疗组高达 **11.2%**。常见的靶向毒性（如斑丘疹、口腔炎、腹泻）绝大多数为 1/2 级，且可通过剂量滴定有效管理。

资深药物化学家、《In the Pipeline》专栏作者 Derek Lowe 对此评价道：
> “借用内源性伴侣蛋白从空间上直接掩蔽效应物结合位点以靶向 RAS 的 ON 状态，是现代药物发现史上针对‘不可能成药靶点’最精妙的智力解决方案之一。它把平坦的蛋白质表面从不可逾越的障碍转化为了成药的抓手。”

生物医药投资机构 Curie.Bio 董事长兼资深创始人 Alexis Borisy 在社交网络上指出：
> “资本市场曾有整整二十年坚信 RAS 是一座无法攻破的堡垒。我们最初用共价化学在 G12C 上撕开了一道缺口，而 RMC-6236 在二线胰腺癌中的获批则证明，分子胶技术有能力在广谱患者群体中瓦解整个致癌核心枢纽。”

### 第二部分：CTX310 与体内 CRISPR-Cas9 基因组永久重写

在小分子领域攻克肿瘤枢纽的同时，《新英格兰医学杂志》发表的 CRISPR Therapeutics 旗下 **CTX310** 一期临床数据，则确立了体内（in vivo）基因破坏技术治疗慢性心血管代谢疾病的临床可行性。

CTX310 将靶点锁定在 **ANGPTL3**（血管生成素样蛋白 3）——一种由肝实质细胞分泌、专门抑制脂蛋白脂肪酶（LPL）和内皮脂肪酶（EL）的糖蛋白。该疗法的设计哲学在于模拟人类自然发生的基因功能缺失突变（家族性低 β 脂蛋白血症）所赋予的心血管保护表型：这类天然突变携带者终身处于极低的 LDL-C 和甘油三酯水平，且无任何肝脏或代谢异常负担。

#### 机制化递送架构：肝向性脂质纳米颗粒（LNP）
CTX310 采用专为肝细胞靶向性工程化改造的静脉输注 LNP 递送系统：
1. **纳米颗粒配方：** 由表观 $pK_a$ 控制在 6.2 至 6.8 之间的可电离氨基脂质、辅助磷脂（DSPC）、胆固醇以及 PEG 化脂质精细配比构成。
2. **ApoE 调理与受体介导内吞：** 在生理血液循环中，纳米颗粒的电中性表面迅速吸附内源性载脂蛋白 E（ApoE），形成生物蛋白冠。该蛋白冠特异性触发肝实质细胞表面低密度脂蛋白受体（LDLR）介导的细胞内吞。
3. **内体逃逸与胞质翻译：** 内体环境的酸化使可电离脂质质子化并带正电，诱导膜结构发生六角相转变从而瓦解内体膜。单导向 RNA（sgRNA）与密码子优化的酿脓链球菌 Cas9（SpCas9）mRNA 被释放至细胞质。
4. **永久性基因敲除：** SpCas9 完成翻译后与 sgRNA 组装，入核并在 *ANGPTL3* 基因的外显子 1 处诱导特异性 DNA 双链断裂（DSB）。细胞利用易出错的非同源末端连接（NHEJ）机制进行修复，产生移码突变（indels），实现该致病基因的永久性沉默。

```
静脉输注 LNP 
   ──► 血液中自组装形成 ApoE 蛋白冠 
   ──► 肝实质细胞表面 LDLR 介导特异内吞 
   ──► 酸诱导内体逃逸与 Cas9 胞质翻译 
   ──► ANGPTL3 基因外显子 1 精准诱导 DSB 
   ──► NHEJ 易错修复产生移码突变 
   ──► 血液循环中 ANGPTL3 蛋白永久清除
```

#### 12 个月持久性终点数据
《新英格兰医学杂志》公布的 1 年期随访结果展示了单次给药后前所未有的持久疗效：
* **循环 ANGPTL3 蛋白：** 在最佳剂量组中，自基线水平平均下降 **79.0%**（最高降幅达 89.0%）。
* **低密度脂蛋白胆固醇（LDL-C）：** 维持长达一年的稳定下降，平均降幅达 **52.5%**（最高降幅达 84.0%）。
* **血清甘油三酯（TG）：** 维持持续下调，平均降幅达 **47.8%**（最高降幅达 78.0%）。
* **安全性与肝毒性监测：** 观察到的短暂、亚临床 1 级转氨酶（ALT/AST）升高在给药后第 7 天达峰，并在第 28 天完全自愈恢复正常。高深度环化测序未检出任何脱靶修复片段，且全疗程无任何治疗相关的严重不良事件（SAE）。

加州大学伯克利分校创新基因组学研究所（IGI）科学主任 Fyodor Urnov 博士在 X.com 发文指出：
> “CRISPR 从需要骨髓移植的体外细胞工程，跨越到了只需 30 分钟日常静脉输注、就能在 12 个月内如画直线般恒定消除心血管危险因子的体内疗法。这标志着体细胞基因编辑正式从昂贵稀缺的定制化治疗，跨入全球大众预防医学的大门。”

CRISPR Therapeutics 首席执行官 Samarth Kulkarni 博士在临床报告中表示：
> “单次干预即实现超过 50% 的 LDL-C 降幅和近 50% 的甘油三酯长达一年的平稳维持，彻底动摇了极其依赖患者终身依从性的传统他汀口服与抗体定期注射范式。”

### 第三部分：FDA“合理机制”监管范式的底层重构

Daraxonrasib 的获批与 CTX310 的临床成熟，共同促成了监管科学底层逻辑的深远变革。2026 年 2 月，FDA 正式出台了**“合理机制框架”（Plausible-Mechanism Framework）**，并同步更新了《利用先验知识发展平台技术指导原则》。

在传统监管路径中，基因疗法即使仅修改单个核苷酸，或抗肿瘤小分子仅切换针对同家族的邻近亚突变，都被要求从头开展全套临床前毒理研究与一期 IND 申报。而在全新的模块化平台框架下，监管逻辑发生了三维转变：
* **软硬件组件解耦（Component Decoupling）：** 监管机构明确将经过验证的递送系统（如标准肝向性 LNP）与催化执行引擎（Cas9 核酸酶、亲环素结合母核骨架）确立为可复用的通用基础设施。
* **跨产品数据桥接（Cross-Product Bridging）：** 一旦平台底座的安全性和体内生物分布档案建立完毕，后续衍生管线的临床审查将聚焦于导向序列特异性、靶点结合确认及疾病相关生化标志物，而无需反复验证底层递送系统的基础毒理。
* **伞状主方案与加速准入（Master Protocols & Accelerated Pathways）：** 该框架为伞状临床试验扫清了障碍，针对罕见亚突变或多代谢通路联合干预的新疗法，可通过生物标志物驱动的合理机制，结合外部自然病史对照，直接走加速审批通道进入商业化。

知名生物医药政策分析师、RA Capital 投资合伙人 Peter Kolchinsky 在行业讨论中生动总结道：
> “FDA 终于开始像对待软件工程一样对待生物医药：一旦运行环境和递送协议栈（LNP 或分子胶底座）通过了编译认证，更换其中的业务载荷（payload）代码，就不再需要把整个编译器从头重写一遍。”

```
传统监管范式：
[ 新靶点导向序列 / 突变体 ] ──► [ 全套临床前毒理 ] ──► [ 一期试验 ] ──► [ 二期试验 ] ──► [ 三期试验 ]

合理机制平台范式：
[ 经认证递送底座 + 平台先验数据库 ] + [ 靶点特异性载荷 Payload ]
                               │
                               ▼
     [ 精简机制验证与靶点结合临床试验 ] ──► [ 商业化加速准入 ]
```

### 工程学视野

泛 RAS 抑制与体内 CRISPR 基因敲除的交汇，正在重划转化医学的物理边界。

在肿瘤学领域，Daraxonrasib 打破了“无共价手柄即无法通过小分子阻断细胞内多蛋白复合物相互作用”的化学教条；在遗传学与代谢医学领域，CTX310 则确立了通过 LNP 递送 RNA 导向核酸酶，能够在高细胞周转器官中实现长达一年的治疗性沉默，且不引发基因组不稳定或慢性免疫排斥。

对于科技决策者、生物计算工程师与产业资本而言，这一演进路径已清晰无误：药物研发的未来属于模块化的大分子组装机器与可编程的基因操作系统——人类正在掌握将慢性病理特征转化为永久纠错代码的工程能力。
