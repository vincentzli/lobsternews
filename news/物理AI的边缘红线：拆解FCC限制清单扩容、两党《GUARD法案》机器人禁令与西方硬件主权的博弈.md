# 物理AI的边缘红线：拆解FCC限制清单扩容、两党《GUARD法案》机器人禁令与西方硬件主权的博弈

2026年7月28日，美国联邦通信委员会（FCC）正式宣布扩大其“受管制清单”（Covered List），将外资生产的“先进机器人设备”纳入其中，直接封杀了中国企业制造的移动双足人形及四足机器人。此举实质上叫停了中国机器人新机型在美国的进口、准入认证与商业销售。尽管美国国家安全机构将其视为保护关键基础设施的里程碑式胜利，但美国机器人研发界却迎来了一场前所未有的生存危机。长期以来，美国高校、顶尖科研机构和AI初创公司都高度依赖中国四足机器人（尤其是宇树科技Unitree的产品）作为标准研究平台。这一极具惩罚性的禁令，将国家安全与学术创新之间的张力推向了风口浪尖。

### 政策催化剂：两党合流的《GUARD法案》（H.R. 9129）
FCC此次重拳出击，其直接推手是2026年6月由众议员John Moolenaar（共和党-密歇根州）、Jay Obernolte（共和党-加利福尼亚州）和Jennifer McClellan（民主党-弗吉尼亚州）联合提出的《防范对抗性机器人主导法案》（简称 GUARD Act，H.R. 9129）。该法案强制要求美国国家安全部门对来自“受关注国家”的人形和四足机器人进行全面的主权安全审查。

为了防止行政部门推诿拖延，GUARD法案设计了一个为期365天的自动触发条款：任何机器人的通信设备或服务，若在法案颁布后的一年内未能通过正式的安全审查，将自动被列入FCC的受管制清单。众议院中共特别委员会主席Moolenaar作为主要立法推动者，警告称：
> “由外国对手制造的人形和四足机器人带来了严峻的间谍活动和网络战风险。它们绝非简单的玩具，而是移动的、具备全向感知能力的数据收集节点，且直接与境外服务器相连。”

由美国国土安全部（DHS）、商务部及国防部（五角大楼）协同开展的跨部门审查，将核心焦点放在了这些机器人作为“移动特洛伊木马”的潜在威胁上。最终，安全部门提交的情报评估直接促成了FCC的即时封杀令。

### 技术拆解：安全漏洞深探
FCC的决策背后，是安全研究人员发现的一系列底层安全漏洞。这些漏洞表明，现有的中国机器人系统极易受到本地及远程的恶意利用与控制：

1. **BLE（蓝牙低功耗）命令注入（CVE-2025-35027）：**
   该高危命令注入漏洞（CVSS评分7.3）波及宇树的Go2、G1、H1和B2等机型，存在于BLE Wi-Fi配置模块中。当用户通过移动App配置机器人的局域网凭证时，相关载荷会通过BLE进行传输。攻击者可以在SSID或密码参数中注入恶意的Shell命令。当机器人尝试应用这些网络设置时，系统会通过 [wpa_supplicant_restart.sh](file:///usr/local/bin/wpa_supplicant_restart.sh) 脚本以 `root` 权限执行这些注入的命令。这使得攻击者可以直接获取机器人主计算模块（通常为NVIDIA Jetson Orin SoC）的 root shell 权限。

2. **CloudSail后门门槛（CVE-2025-2894）：**
   在宇树Go1系列中，研究人员揭示了一个嵌入在 CloudSail 远程访问服务集成中的持久性后门。机器人会与外部服务器维护一个持续的 WebSocket 连接。持有有效 API 密钥的攻击者可以完全绕过本地身份验证，远程劫持机器人的肢体动作、强行启动车载相机阵列、实时监听音频，并窃取高精度的GPS及定位遥测数据。

3. **DDS通信层漏洞（CVE-2026-27509 & CVE-2026-27510）：**
   最令人担忧的威胁媒介存在于其实时通信中间件中。宇树机器人采用数据分发服务（DDS）来实现高级计算单元（运行ROS2）与实时电机控制器之间的低延迟通信。由于宇树默认配置下的DDS流量未加密且缺乏严格的身份验证，同一局域网内的攻击者可以通过广播恶意DDS数据包来篡改移动数据库，或者直接覆盖电机控制回路中的PID控制器参数以及活动关节限制。这极易导致关节剧烈过度伸展、电机烧毁或机器人物理性折断。

4. **加密套件硬伤：**
   对宇树专有的“FMX”加密封装的分析显示，其在所有出厂设备中均使用了硬编码的静态密钥。这意味着任何拿到固件镜像的攻击者都可以轻松解密配置文件、微调本地遥测参数，并对核心的控制算法进行反向工程。

### FCC管制清单下的软件生态绞杀
FCC的实体清单制裁不仅阻断了硬件的物理输送，更彻底重构了中国机器人平台的软件生命周期：
* **拒绝新增设备授权：** FCC将不再为受限制实体的“先进机器人设备”发放新的无线电许可。这意味着类似宇树新曝光的G1人形机器人迭代机型，在美国境内无法合法激活或运行其无线电模块。
* **封禁软件更新：** FCC对“受管制设备”的定义已延伸至软件更新及云端遥测。受限制企业被禁止向美国境内的设备推送固件更新，亦无法接入位于美国的云端基础设施。
* **强制“本地网络化”：** 目前已在美国运行的存量机器人必须断开一切公共广域网（WAN）路由。任何与中国云服务器进行的遥测数据传输、模型训练或诊断日志交互，在法律层面已被完全禁止。

### 学术与创新的两难：巨大的“硬件鸿沟”
这一禁令撕开了美国学术界与产业政策之间的巨大鸿沟。由于中美机器人硬件之间存在着极其悬殊的性价比差距，美国高校、研究实验室和初创公司对中国四足机器人有着极强的依赖性：

| 平台 | 制造商 | 产地 | 预估基础售价 (美元) | 主要市场 |
| :--- | :--- | :--- | :--- | :--- |
| **Unitree Go2 Pro** | 宇树科技 | 中国 | $1,600 | 学术与开发者 |
| **Unitree B2** | 宇树科技 | 中国 | $15,000 | 工业级科研 |
| **Spot** | 波士顿动力 | 美国 | $75,000 | 商业与工业 |
| **Vision 60** | 幽灵机器人 (Ghost Robotics) | 美国 | $150,000+ | 军事与安防 |

这一性价比差距让科研人员忧心忡忡。知名机器人学者 Chris Paxton 指出了高昂的科研准入门槛：
> “禁用像宇树这样价格亲民的研究平台并不能保护美国的技术。相反，这在强迫学术实验室做出痛苦的选择：要么花7.5万美元买一台波士顿动力的Spot，要么直接关停他们的四足机器人研究。我们正在扼杀自己的人才储备。”

AI初创公司 Physical Intelligence 的人工智能副总裁 Eric Jang 也指出，廉价硬件对物理AI（具身智能）的发展至关重要：
> “AI的研究速度与我们能够并行运行的物理机器人数量直接成正比。如果西方实验室无法获取高产能、低成本的硬件，我们就会在具身智能的场景学习曲线上被对手彻底甩开。”

然而，禁令的支持者（包括 Agility Robotics 等美国本土企业）则反驳称，依赖受补贴且存在安全隐患的外国硬件是一种结构性的脆弱性。他们援引了DJI大疆在无人机市场的历史先例，指出学术科研上图一时便宜，最终会导致整个国内机器人产业的彻底失守。

### 合规窗口：“条件性批准”的防御性加固要求
针对国防承包商、联邦实验室及特定学术机构，以五角大楼为首的国家安全机构为现存中国机器人的合规运行开辟了一条“条件性批准”（Conditional Approval）通道。要获得豁免，相关机构必须执行极其苛刻的物理与软件加固协议：
1. **物理拆除无线通信（RF De-soldering）：** 运行人员必须物理切断板载Wi-Fi和蓝牙模块。这需要拆开机器人底盘，强行焊下或剪断同轴射频天线连接，迫使机器人只能通过有线以太网或经过加密的本地微型电台进行通信。
2. **固件深度净化（Firmware Sanitization）：** 必须彻底清除宇树原厂的操作系统和控制软件。设备必须重新刷写经过安全审计的开源替代系统（如基于安全Linux发行版如带有实时 RT-PREEMPT 补丁的 Ubuntu LTS，并运行干净的 ROS2）。
3. **零信任内网拓扑（Zero-Trust Intranet Topology）：** 机器人必须在完全物理隔离、无广域网路由的虚拟局域网（VLAN）中运行。DDS流量必须配置 DDS Security 扩展（SNDS）或通过加密VPN联接传输，以防止局域网内的数据包注入攻击。

### 西方硬件供应链的“回流”困局
FCC禁令在市场上留下了一个巨大的真空。为了填补这一空白，西方供应商必须加快具身智能硬件的本土化生产与规模化进程。然而，重建一条独立的本土供应链面临着多重制造瓶颈：
* **执行器与电机功率密度：** 中国制造商得益于高度集成的本土产业集群，在超高扭矩无刷电机和行星齿轮减速器的配套上优势明显。西方本土化重建需要实现高功率密度、低成本无刷执行器的规模化量产。
* **谐波减速器（Strain Wave Gears）：** 双足人形和四足机器人的关节传动高度依赖谐波减速器。虽然像 Harmonic Drive LLC 这样的巨头能生产高端减速器，但其价格相比中国量产的同类产品昂贵得令人望而却步。
* **感知元器件自主：** 深度相机、固态激光雷达（LiDAR）以及惯性测量单元（IMU）必须转而采购自非对抗性国家的合规厂商，彻底绕过 RoboSense（速腾聚创）或 Hesai（禾赛科技）等主导市场的中国供应商。

在2025年1月秘密就长达数年的专利纠纷达成和解后，波士顿动力（Boston Dynamics）与幽灵机器人（Ghost Robotics）开始联手游说美国政府出台协同的“国家机器人战略”。通过共享资源并争取联邦研发补贴，本土供应商试图拉低生产成本。

长远来看，西方具身智能的未来取决于风险资本和产业政策能否迅速催熟 Agility Robotics（Digit）、Figure（Figure 02）以及特斯拉（Optimus 系列）等本土企业，使其在价格上——而不仅仅是在安全合规上——具备与中国产品一较高下的实力。在此之前，美国的机器人研究将不得不经历一段痛苦的过渡期：用科研迭代的降速，来换取所谓的安全。
