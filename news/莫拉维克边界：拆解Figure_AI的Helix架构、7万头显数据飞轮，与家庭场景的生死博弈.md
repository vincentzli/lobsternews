# **莫拉维克边界：拆解Figure AI的Helix架构、7万头显数据飞轮，与家庭场景的生死博弈**

在过去三十六个月内，人形机器人领域正在经历一场本体论层面的剧烈范式转移，其震感不亚于2017年前后自然语言处理（NLP）领域的前夜：经典运动学状态机被全面清退，端到端具身基座模型（End-to-End Foundation Models）以不可逆的姿态走上历史前台。这一技术路线演进最具进攻性的注脚，出现在Figure AI最新的工程里程碑中——依托全新升级的视觉-语言-动作（Vision-Language-Action, VLA）模型Helix 2.5，其第三代硬件平台Figure 03不仅完成了无先验标注环境下的自主垂直阶梯攀爬，更在旧金山湾区30个未建模的真实家庭中，实现了零样本柔性物体操作（Zero-Shot Deformable Manipulation）成功率高达6倍的跳跃。

对于长期被禁锢在汽车焊装工位与刚性夹具之中的人形机器人行业而言，Figure将矛头直指高度非结构化的消费级家庭环境，是一场极其激进的工程豪赌。然而，在病毒式传播的演示视频背后，一场横跨机器人学实验室、前沿AI研究机构与硬核工程社区的论战正全面爆发：物理世界的尺度定律（Scaling Laws）究竟是否成立？数据源头的成色几何？纯视觉模仿学习是否真能彻底驯服物理世界微观接触动力学的“莫拉维克悖论”？

### Helix架构拆解：分层VLA的解耦与重构
经典的人形机器人控制管线，本质上是一组被割裂在孤岛中的功能模块：高阶符号规划器向数值逆运动学（IK）求解器下发空间路径点，求解器将位姿解算为关节设定点，再交由比例-积分-微分（PID）算法或基于二次规划（QP）的模型预测控制（MPC）执行。Helix则系统性地击碎了这种人工堆叠的笛卡尔轨迹启发式逻辑，用一套高吞吐的统一神经网络取而代之。

Helix在三个时钟频率严格同步的时域分层中运行：
1. **System 2（认知规划层，~5–10 Hz）：** 核心为一个多模态视觉-语言模型（VLM）底座，实时处理高分辨率多目视频流并理解自然语言指令。它的核心能力在于3D空间几何与物理语义的锚定——例如识别被罩的缝合边、脏衣篮的边缘折痕，或是直梯横档在三维空间中的拓扑延伸。关键在于，System 2并不输出僵硬的几何坐标，而是向下流转连续的“潜在目标Token”（Latent Goal Tokens）。
2. **System 1（视运动控制策略，~200 Hz）：** 这是一个基于扩散模型的动作分块Transformer（Diffusion Action-Chunking Transformer）。它将System 2下发的潜在目标，与本体第一人称视角（Egocentric）的视觉Token进行交叉注意力融合（Cross-Attention），在一个滑动的时序窗口内，实时预测末端执行器的连续轨迹（涵盖6自由度SE(3)空间位姿与指关节开合角度）。通过在统一时间块内批量预测动作轨迹，而非自回归式地逐帧步进，Helix从数学机制上有效抑制了高频执行器常见的机械抖动（Chatter）。
3. **System 0（全身动力学稳定层，~1 kHz）：** 部署在机器人嵌入式硬实时计算单元上的物理兜底控制。它直接接管导纳控制（Admittance Control）、关节力矩饱和限制与动态质心（CoM）平衡，确保双足底盘在突发外力冲击或复杂动力学耦合下维持动力学平衡。

这种三层级联架构在垂直直梯攀爬实验中经受了极限压力测试。在控制理论中，攀爬梯子属于典型的非完整约束（Non-holonomic）控制难题：机体必须在陡峭的重力载荷下，交替维持三点与四点闭式运动学链（Closed Kinematic Chains）。抓握点哪怕出现一毫米的偏差或脚部打滑，机体质心就会立刻逸出支撑多边形基座之外。Helix完全摒弃了激光SLAM点云重建或人工放置基准标记码（Fiducial Markers）的旧范式，纯粹依赖手爪合拢接触梯级横档时的端到端闭环视觉伺服与动态力矩自适应，完成了整套攀爬流。

“我们正在系统性地淘汰人工编写的启发式规则、解析逆运动学以及预设状态机，”Figure首席执行官Brett Adcock公开表示，“Helix实现了从光学光子到电机动作的直接映射。随着算力、模型参数与物理Token规模的持续扩展，这套系统正在涌现出一种直觉性的物理接触理解力，而这是经典控制理论苦熬了五十年都未能解决的泛化难题。”

### “Index”数据引擎：7万台空间计算头显构筑的具身飞轮
制约具身智能规模化扩展的核心瓶颈从来不是算力上限，而是高质量物理世界数据的赤贫。当通用大语言模型（LLM）能够在万亿级网页文本与视频Token中恣意浸润时，机器人领域却长期受困于遥操作机械臂（如ALOHA、GELLO或全身外骨骼装备）的数据荒漠。这类系统不仅硬件造价动辄数万至数十万美元，更高度依赖专业人类技师的手动示教，单台设备每年能产出的有效示范时长往往不过几千小时。

Figure的战略破局点在于其名为**Index**的分布式数据引擎——它绕过了沉重且高昂的物理遥操作机架，直接从近7万名佩戴空间计算头显（以Apple Vision Pro和Meta Quest为主）及传感器移动套件的周活用户中，众包人类日常行为数据。

```
[7万头显周活用户] ──► [第一人称RGB-D数据] ──► [时空SLAM位姿重建]
                                                        │
                                                        ▼
[跨本体运动学重定向] ◄── [MANO手势 / SMPL-X全身网格参数化提取]
             │
             ▼
[Helix无监督预训练管线] ──► [零样本柔性物体操作成功率激增6倍 (9% -> 56%)]
```

将杂乱、非受控的人类家庭日常动作，转化为机器人可执行的高保真动力学控制策略，依赖于一套高度精密的解耦与空间映射流水线：
* **时空SLAM与深度感知流解析：** 原始第一人称RGB-D数据被实时输入在线SLAM引擎，人类操作者的头部朝向、视线凝视向量（Gaze Vector）及躯干姿态被精确锚定在绝对度量尺度的三维世界坐标系中。
* **生物力学状态参数化提取：** Index引入参数化MANO模型提取手部21个3D关键点轨迹，并利用SMPL-X全身模型抽离躯干运动拓扑，从而将人类运动动力学从复杂的室内视觉噪点中彻底剥离。
* **跨本体运动学重定向（Cross-Embodiment Retargeting）：** 人类手部拥有超过27个自由度以及极其复杂的生物软组织柔顺性；Figure 03的灵巧手则是基于电机直驱或腱绳驱动的16至20自由度拓扑。Index需要将人类连续的指尖运动空间映射至机器人的可达空间包络线内，并利用带约束的最优化算法求解，确保生成的轨迹严苛收敛于电机角速度阈值与力矩饱和极限之内。
* **自监督动作表征预训练：** 最终重定向后的动作轨迹与高频视觉帧在时域上严密对齐并完成离散化，构成了Helix庞大的底层自监督预训练动作语料库。

该数据管线的威力在最新的家庭测试中显现：在30个完全未被建图的湾区真实民居中，面对折叠衣物、铺平床单、杂物分拣等极度复杂的柔性物体（Deformable Objects）场景，未注入Index预训练的模型零样本操作成功率仅有9%，而Helix 2.5直接将这一基准线拉升到了56%。

在机器人控制学中，柔性物体操纵长期被视作“终极大Boss”。与拥有固定几何构型的汽车冲压钣金件不同，纺织物拥有近乎无限维度的自由度、非线性摩擦滞后效应（Frictional Hysteresis）以及严重的自遮挡现象。Helix在未经历任何显式有限元物理仿真（FEA Simulation）推演的情况下，纯粹通过从第一人称人类操作视频中内化空间拓扑特征，自行构建出了织物操纵的原语认知。

### 路线大分裂：视觉行为克隆 vs. 触觉物理真实
尽管56%的成功率跃升在媒体端引发了轰动，但在学术界、顶级灵巧手操纵实验室以及Reddit的r/robotics社区，这一路径却遭遇了空前激烈的技术反弹。争论的核心直指本质：**纯视觉主导的行为克隆（Behavioral Cloning），究竟能否取代基于闭环力控的高频触觉反馈？**

在Reddit的r/robotics技术论坛上，一条获得极高赞同的资深机械操纵工程师评论直指其要害：
> “试图通过第一人称视频预训练来宣称攻克柔性物体，完全是对接触力学中莫拉维克悖论的无视。基于视频训练的扩散模型确实能‘预测’布料边缘在视觉画面中应当如何形变位移，但它对材料内部的剪切力分布、握持界面内部的微滑移（Micro-slips）、以及张力梯度的传递一无所知。你无法通过行为克隆绕过摩擦接触的动力学奇异点。只要被子一厚，手掌摄像头视线被遮挡的那一毫秒，这个所谓的VLA策略本质上就是在依靠视觉残影进行脆弱的开环裸奔。”

iRobot联合创始人、行为主义机器人学泰斗罗德尼·布鲁克斯（Rodney Brooks）同样对此泼下冷水：
> “如果一个机器人没有与物理世界发生真实的受力接触，它实际上什么也没做。真实世界不是互联网视频剪辑。叠一件领口翻在里面的衬衫不是互联网级别的计算机视觉任务，它是一个纯粹的接触动力学与高频触觉感知问题。当前的人形机器人叙事，习惯于将视频序列的模式复刻误判为对物理实体世界的掌控力。真正的家庭可靠性，需要多轴力矩反馈与高密度触觉传感阵列，而不是塞进去更多网页数据。”

纯视觉行为克隆更隐蔽的致命硬伤在于数学上的**协变量偏移**（Covariate Shift，由Ross和Bagnell提出的 $O(\epsilon T^2)$ 级复合误差发散效应）。在诸如整理床铺这类的长程复合任务中，机器人初始铺展动作中极其微弱的握持偏差，都会指数级放大并彻底改变布料随后的几何折痕状态。如果这个由误差引发的新状态恰好超出了Index预训练数据的覆盖包络，扩散模型就会输出一个略显变形的动作块，进一步将物理系统推向训练分布之外（Out-of-Distribution, OOD），直至系统在复合误差中不可逆地走向任务崩溃。

面对这一诘难，Figure的算法防线建立在数据多样性的暴力美学之上：只要预训练数据的场景与交互丰富度跨越临界点，现实家庭中便不再存在绝对意义上的OOD状态。与此同时，Figure 03在硬件端并非完全放弃触觉，其柔顺指尖阵列与掌心确实集成了触觉传感器与近场微距相机。然而业界的核心疑虑依然未解：Helix究竟是将高维的多轴剪切力和法向力张量原生注入了200 Hz的扩散Transformer内部，还是仅仅将这些触觉读数用作了底层急停与防滑脱的安全阈值裁决器？

相比之下，英伟达具身AI负责人Jim Fan（范麟熙）博士则对Index展现出的跨本体潜力持有极具扩张性的乐观态度：
> “机器人社区在过去整整十年里，都在纠结人类视频到底能否跨越具身鸿沟迁移到机器人机体上。Index的工程实践彻底证明了空间表征在物理维度上的普适性。人类的肉手与电驱灵巧手虽然在运动学构型上差异显著，但物理世界向操纵者开放的3D功能可达场（Affordance Fields）是完全恒定的。VLA基座模型正在完美复刻通用语言模型的算力扩展定律。”

### 工业严苛性 vs. 家庭热力学荒原：商业维度的残酷账本
将视线拉回现实维度，Figure当前展现出了一条极具反差的技术路线图：一面是在宝马斯帕坦堡（Spartanburg）工厂沉淀严苛工业测试，另一面则是向家庭消费场景做战略倾斜。

```
┌─────────────────────────────────┬──────────────────────────────────┐
│ 工业汽车制造场景 (宝马Spartanburg) │ 消费级家庭场景 (Consumer Homes)   │
├─────────────────────────────────┼──────────────────────────────────┤
│ 节拍时间 (Cycle Time): <60秒确定性│ 节拍时间: 异步松散/允许等待中断  │
│ 可靠性阈值 (Reliability): 99.99% │ 可靠性阈值: 约95%即可获得初步可用性│
│ 光照/物理环境: 静态、受控工装夹具 │ 光照/物理环境: 绝对非受控、高动态  │
│ 操作对象物理特性: 刚性冲压钣金件  │ 操作对象物理特性: 无限维柔性织物   │
│ 投资回报模型: 15万美元CAPEX回本周期│ 投资回报模型: 需压至3万美元以下消费品│
└─────────────────────────────────┴──────────────────────────────────┘
```

在宝马斯帕坦堡工厂内，前代机型Figure 02曾经历过长达11个月的实机驻场验证，执行过数万辆宝马X3车型的底盘冲压件抓取与高精夹具嵌合。在汽车焊装体系中，工程运行边界是冷酷且近乎病态的：
* **节拍时间（Takt Time）** 以秒甚至毫秒为刻度做严格裁决；
* **可用性** 必须击穿工业六西格玛标尺（99.999%），任何一次导致总装线意外停滞的故障，在行业标准下都意味着每分钟数万美元的直接损失；
* 所有的光照环境、工装定位以及制造执行系统（MES）都是为了收敛不确定性而设计。

斯帕坦堡的实景验证之所以能够落地，是因为物理与环境变异性的边界被死死锁死在人造的刚性牢笼之内。然而，家庭起居室在控制理论视角下，是一片未受任何熵减约束的“热力学荒原”：
* 光照强弱与投射角度在一天内动态剧烈漂移；
* 地面摩擦系数可在打蜡实木地板与长毛地毯之间断崖式突变；
* 场景内存在不可预测、具有极高安全权重的动态实体（如乱窜的宠物与蹒跚学步的婴儿）；
* 每一个等待处理的操作对象，都带有极其随机的几何形变与物理属性各向异性。

这就引出了一个残酷的商业回报悖论。在汽车制造厂，一台售价15万美元的人形机器人，只要能替代三班倒、每小时综合用工成本高达45美元的装配技工，就能在两年内迅速打平资本支出（CAPEX）。但在家庭场景中，一台人形机器人所面临的竞争对手，是成本低廉且成熟可靠的专用家电组合（洗衣机、干衣机、扫地机）以及高度灵活的人工家政服务。

当一台人形机器人在折叠衣物上取得56%的零样本成功率时，它在科研领域足以登上顶刊封面，但在商业上却是一场绝对的灾难：没有消费者愿意为一台售价3万至5万美元、每操作两次就会扯掉被套或彻底宕机一次的机器买单。要想具备真正的家庭消费变现可能，机器人必须将日常家务操作的成功率推升至95%以上，而在涉及人身安全的交互场景中，这个数字必须跨越99.9%的绝对红线。

### 物理世界的尺度定律终局
Figure 03与Helix 2.5所构建的技术范式，无疑确立了一个清晰的趋势：借助海量分布式人类视频流，视觉-语言-动作模型完全有能力在不依赖传统遥操作的前提下，内化物理世界的低阶操作先验。而直梯攀爬的突破，更是以震撼的工程实证宣告了全身连续动态控制可以彻底从传统运动学状态机的束缚中挣脱。

然而，横亘在56%的惊艳演示与99.9%的高可用商业落地之间的鸿沟，才是现代机器人工程学最残忍的修罗场。在大型语言模型中，千分之一的Token幻觉不过是一句无伤大雅的代码Bug或逻辑跳跃；但在一台重达140磅、与人类共处同一物理空间的金属人形机体上，对接触法向力的一次误判，或是对摩擦系数的一次幻觉，都可能直接演变为重物砸落或从楼梯上失控倾覆的灾难性事故。

随着Figure及其身后的一众具身独角兽加速驶向商业量产的深水区，整个行业必须正面回答那个悬而未决的底层诘问：再堆叠一个数量级的空间视频Token，真能奇迹般抹平接触力学最幽深的摩擦奇异点吗？抑或是，人类终将在这场狂飙中再度幡然醒悟——眼睛负责打量这个世界，但唯有毫秒级的真实触觉，才能真正统治它？
