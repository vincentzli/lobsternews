# 3000亿美元的重锚：甲骨文举债豪赌OpenAI，一份泄密账本引发的AI估值裂变

2026年10月8日周四，甲骨文公司（Oracle Corporation）股价重挫5.48%，报收135.69美元。这轮单日抛售直接蒸发了该公司约235亿美元的市值，并在整个AI概念板块掀起了一场剧烈地震。然而，触发这场恐慌的导火索并非来自甲骨文奥斯汀总部的财报爆雷，而是《金融时报》（Financial Times）披露的一份关于OpenAI的内部机密账本。

这份泄露的文件显示，截至2026年9月30日，这家人工智能领头羊的年化营收运行率（annualized revenue run rate）正逼近500亿美元。尽管在过去12个月内，年化500亿美元的顶线数据意味着高达77%的狂飙突进，但这依然远低于机构交易台在短短两周前计入AI基础设施估值中的“耳语预期”（whisper numbers）——彼时华尔街私下流传并定价的数字在680亿至700亿美元之间。预期的落空迅速外溢至半导体与云计算产业链：纳斯达克综合指数当日下跌1.25%，英伟达下挫2.8%，而CoreWeave与博通等纯算力概念股的跌幅则在2.4%至4.1%不等。

这200亿美元的预期鸿沟，事后被证实更多源自激进的财务估值模型偏差，而非终端需求的突然萎缩。此前，硅谷投资人在试图将OpenAI与宿敌Anthropic进行横向对比时，通过计算年化总账单流水（gross annualized billings）人为推高了OpenAI的指标——把通过微软Azure等第三方云平台分销的转手销售额全额计入。Anthropic公布的总营收向来包含亚马逊AWS和谷歌云（Google Cloud）的分销加价，而OpenAI的内部口径则是其直接收取的净收入。

然而，这番口径澄清并未抚平宏观交易员的焦虑。2025历年，OpenAI在录得130.7亿美元营收的同时，净亏损高达385亿美元，巨额的模型训练支出与算力消耗成了难以承受之重。即便OpenAI的企业级营收运行率在2026年第三季度激增107%，管理层也依旧坚持在2026年12月31日前实现年化净营收突破700亿美元的业绩指引，这份外泄的底牌依然击碎了市场关于AI能够“毫不费力、无限指数级变现”的暴利神话。

对甲骨文而言，对OpenAI的敏感度不仅深入骨髓，而且风险高度集中。早在2025年9月，甲骨文就与OpenAI敲定了一份里程碑式的五年期、价值3000亿美元的云基础设施算力大单。如今，仅这单一客户的采购承诺，就占据了甲骨文6640亿美元剩余履约义务（RPO）的约45.2%。尽管甲骨文云基础设施（OCI）在2027财年第一季度交出了同比暴增121%的耀眼答卷，但支撑这种超速增长的，是一场史无前例的举债资本开支狂欢。甲骨文在2026财年投入了557亿美元的资本支出，同比飙升162%；联席首席执行官克莱·马古尔克（Clay Magouyrk）与迈克·西西利亚（Mike Sicilia）更是将2027财年的资本开支指引上调至900亿至950亿美元，在客户预付款到账前，预计需要耗费约700亿美元的直接现金流支出。

Reddit上的美股散户大本营r/wallstreetbets与r/stocks在整个交易日充斥着对这种客户集中度风险的毫不留情的冷嘲热讽。一篇被广泛转发的热帖将超大规模云厂商与前沿AI实验室之间的共生关系戏谑为“一场加了杠杆的小组作业——巨头们本质上在靠举债互相给对方注资刷单造增长，然后一起等催债人上门”。另一位散户直言，甲骨文亲手搭建了一个“循环基建债务”模型：一旦OpenAI在企业端商业化变现失速，甲骨文手里剩下的将是用借来的百亿美元堆砌而成的几十万个专用服务器机柜。而在散户讨论社区StockTwits上，随着甲骨文股价下探135美元支撑位，相关讨论热度飙升超过340%，逆势看多的做多派则反唇相讥，认为在OpenAI净增速依然维持在70%以上的大背景下，市场荒谬地“把3000亿美元有合同背书的在手订单当成了负债，而不是资产”。

但真正令机构信贷市场夜不能寐的底层隐患，是在“长期高利率”（higher-for-longer）环境下吞吐庞大债务的沉重代价。在执行董事长兼首席技术官拉里·埃里森（Larry Ellison）的铁腕掌舵下，甲骨文的长期债务规模已突破1600亿美元大关，资产负债率被推高至约3.5倍的警戒水平。2026年7月，标普全球评级（S&P Global Ratings）将甲骨文的长期发行人信用评级下调至BBB-——距离投机级（即“垃圾级”）仅一步之遥。标普在降级报告中特别指出，其未完成订单中极端的客户集中度以及长期负向的自由现金流是核心隐患。雪上加霜的是，在美联储主席凯文·沃什（Kevin Warsh）于2026年9月加息25个基点将联邦基金利率目标区间定在3.75%至4.00%后，基准10年期美债收益率在10月5日冲上5.31%的52周高点后，目前仍徘徊在5.24%的高位。在高企的无风险利率面前，扛着1600多亿美元的负债利息已成为吞噬利润的残酷现实。

加剧华尔街焦虑情绪的，还有现实工地中看得见摸得着的落地交付瓶颈。2026年9月下旬，甲骨文针对其新墨西哥州唐娜安娜县（Doña Ana County）的“木星项目”（Project Jupiter）正式发出了不可抗力通知。这个规划容量高达2.45吉瓦（GW）的数据中心园区，本是多吉瓦级“星际之门”（Stargate）基建蓝图中的旗舰项目。然而，由于环保审批遭拒，一条关键的天然气管道建设被迫推迟到2027年2月。为了确保一期工程按期交付，甲骨文不得不动用成群的车队，通过卡车向这处沙漠腹地运送压缩天然气（CNG）。在二级信贷市场上，支撑“木星项目”的180亿美元银团贷款价格已经跌至面值的89到91美分。更让资产负债表雪上加霜的是，甲骨文与蓝猫头鹰资本（Blue Owl Capital）旗下开发商STACK Infrastructure签署的主租赁协议中，包含极其严苛的“无论如何必须付款”条款（hell-or-high-water clauses）——这意味着无论当地公用事业电网能否通电让服务器点亮运转，甲骨文每一分钱的机房租金都分文不能少。

为了填补2027财年资本开支与经营现金流之间高达250亿美元的缺口，甲骨文已经展开与阿波罗全球管理（Apollo Global Management）、高盛（Goldman Sachs）等私募股权与私人信贷财团的谈判，同时谋划通过发行结构性债务和股权再融资筹集高达400亿美元的弹药。但随着整个企业级软件估值倍数持续被压缩，投资者开始严肃拷问：云巨头们是否在终端企业级软件真正产生充沛现金流之前，过早数年透支建设了这种折旧速度惊人的GPU算力产能？OpenAI年化500亿美元净收入与华尔街700亿美元耳语共识之间的裂痕证明，即便作为人类商业史上扩张速度最快的技术平台，也逃不过基础算术法则的审判。在135.69美元的价位上，甲骨文的股票价值不再取决于拉里·埃里森描绘的云帝国宏图，而是系于最原始的现实：一个至今仍在巨额失血的单一房客，究竟能否在现实中赚出足够的真金白银，替那张3000亿美元的滔天账单买单。
