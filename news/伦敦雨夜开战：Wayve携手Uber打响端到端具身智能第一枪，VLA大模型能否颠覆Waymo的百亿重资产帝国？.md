# 伦敦雨夜开战：Wayve携手Uber打响端到端具身智能第一枪，VLA大模型能否颠覆Waymo的百亿重资产帝国？

2026年9月3日，自动驾驶领域旷日持久的技术路线之争，在伦敦湿滑泥泞的柏油路面上迎来了最具历史意义的分水岭。英国自动驾驶先锋企业 Wayve 联合全球出行巨头 Uber，在英国首都正式上线了该国首个商业化运营的监督式自动驾驶网约车服务。

如今，在伦敦市区打开 Uber 呼叫 UberX、Uber Comfort 或 Uber Electric，驶到路边接驾的很可能是一辆福特电马（Mustang Mach-E）。操纵这台纯电 SUV 方向盘与踏板的，不再是传统机器人学堆砌而成的硬编码控制流水线，而是一个具备实时推理能力的端到端视觉-语言-动作（Vision-Language-Action, VLA）基础模型。在服务正式上线的首日，已有超过14万名伦敦市民通过 Uber 应用内的行程偏好设置完成了试乘预约。

然而，在这场充满未来感的商业狂欢背后，是一场在人工智能学术界、监管机构与华尔街分析师之间激化已久的底层哲学交锋。与 Alphabet 旗下的 Waymo、亚马逊的 Zoox 以及百度 Apollo 坚守的“多阶段解耦流水线 + 厘米级高精地图（HD Maps）”技术壁垒截然不同，Wayve 将全部身家押注在纯靠数据驱动、自回归生成驾驶动作的端到端大模型之上。

正如 Wayve 联合创始人兼 CEO Alex Kendall 在发布现场所言：
> “我们非常自豪能把 Wayve AI Driver 首次推向公众，而且就在我们的主场伦敦——全球路况最复杂的城市之一。如果你能证明这套技术能搞定伦敦，你基本上就能在世界任何一个角落畅行无阻。这里是地表最残酷的试金石。”

要理解为什么这次商业落地被视为具身智能（Embodied AI）的“斯普特尼克时刻”，我们必须彻底拆解当下正在物理世界中殊死搏杀的两种工程流派。

### 架构分野：VLA 基础模型对抗经典模块化工程栈

过去十五年来，全球自动驾驶行业奉为圭臬的一直是严格解耦、环环相扣的模块化架构：
1. **感知（Perception）：** 融合激光雷达点云、毫米波雷达反射波与高清相机画面，生成空间包围盒（3D Bounding Boxes）、语义分割掩码和动态目标追踪轨迹。
2. **定位（Localization）：** 将传感器实时数据与离线测绘的厘米级高精矢量地图进行特征匹配，确认自车在时空网络中的绝对坐标。
3. **预测（Prediction）：** 借助运动学模型或预测网络（例如 Waymo 的 Wayformer），推演周围交通参与者未来数秒内的潜在轨迹。
4. **规划与控制（Planning & Control）：** 在既定安全边界内，通过二次规划或点阵搜索（Lattice Planners）求解非线性代价函数最小化问题，最终下发转向、节气门开度和制动等控制指令。

Waymo 与 Zoox 凭借这套工程栈，在凤凰城、旧金山和洛杉矶等城市跑通了惊人的商业里程。然而，批评者一针见血地指出，模块化架构存在致命的系统性缺陷：**级联误差放大（Cascading Error Compounding）、严重依赖手工规则的启发式瓶颈，以及极为沉重的地理扩张摩擦力**。如果在感知层将一个被风吹起的塑料袋误判为混凝土路障，下游规划器将机械地继承这一致命错误，甚至触发剧烈急刹，除非工程师为其单独手写一条异常豁免逻辑。

Wayve 研发的“AI Driver”彻底掀翻了这一传统范式。它将驾驶本质定义为一个连续的端到端序列建模问题：**输入传感器光子流，直接输出轨迹航点、曲率与加速度**。

```
[ 经典模块化技术栈 (Waymo / Zoox) ]
传感器数据 + 高精地图 ➔ 感知(3D Bounding Boxes) ➔ 行为预测 ➔ 规则规划器 ➔ 底盘线控执行
                                                 *存在信息瓶颈与级联误差*

[ Wayve AI Driver (端到端 VLA 大模型) ]
多模态视频与雷达Token ➔ 生成式世界模型(GAIA-1) + VLA模型(LINGO-2) ➔ 连续轨迹路标 + 决策推理Token
                                                *隐式特征表征与全流程可微梯度*
```

支撑 Wayve 整个技术架构的，是其底层深度咬合的三大基础模型：
*   **LINGO-2（闭环视觉-语言-动作模型）：** 如果说 2023 年发布的初代 LINGO-1 只是一个坐在副驾驶做路况解说的“旁观者”，那么 LINGO-2 则真正完成了感知与底盘控制的闭环。它将视觉 Transformer（ViT）与自回归语言模型融为一体，既接收环视车载摄像头输入的流媒体视频，也理解自然语言提示词；模型不仅以自回归方式直接吐出连续的驾驶轨迹航点，还能同步输出解释性语言 Token，实时回答它“为何刹车、为何礼让、为何向外微调路线”。
*   **GAIA-1（自动驾驶生成式世界模型）：** 这是一个基于 PB 级道路视频、文本提示和自车操纵指令训练的多模态世界模型。GAIA-1 采用离散 Token 的无监督序列建模架构，能够在潜在空间中预演符合现实物理规律、逼真的未来行车场景，无需依赖人工标注的 3D 几何要素，便掌握了物体遮挡关系、碰撞常识以及人类意图博弈。
*   **PRISM-1（4D 动态场景重建）：** 基于纯视觉输入的 4D 高斯泼溅（4D Gaussian Splatting）技术，PRISM-1 可以在时空维度重建高度保真的动态城市实景，彻底甩掉了高成本激光雷达与人工标注边界框的束缚，将几乎无损的真实场景数字化逆向喂回仿真训练循环。

图灵奖得主、Meta 首席 AI 科学家 Yann LeCun 作为 Wayve 的早期投资人，一直对纯大语言模型和机械的经典机器人架构持保留态度：
> “多年来我一直在呼吁世界模型与自主规划的结合，而 Wayve 的 GAIA-1 模型令人信服地证明了这一思路在自动驾驶领域的巨大潜能。”

前特斯拉 AI 总监 Andrej Karpathy 同样将这一范式转移视为“软件 2.0（Software 2.0）”的必然演进：
> “神经网络正在自底向上彻底吞噬整个软件栈。一开始你只是用神经网络做感知，但假以时日，所有的手工规则、运动预测模型与路径规划器，最终都会被一个端到端可微的统合系统所取代。”

就连守擂者 Waymo 也感受到了基础模型的万有引力。2024年底，Waymo 研究团队低调公布了 **EMMA**（基于 Gemini 架构的自动驾驶端到端多模态模型），探索如何在统一 Token 空间内实现从原始像素到轨迹图的映射。但不同的是，当谷歌仍把 EMMA 圈禁在实验室阶段时，Wayve 与 Uber 已经把端到端大模型推上了真实的载客公路。

### 高精地图困局：当自动驾驶撞上伦敦的维多利亚时代街巷

Wayve 与传统 Robotaxi 阵营最尖锐的分歧，在于对高精地图（HD Maps）的依赖程度。

Waymo 的运营铁律是“兵马未动，粮草先行”：进入任何一个新区域之前，必须派遣测绘车队成百上千次地扫描每一寸道路，构建出密集的激光雷达点云，精确标注路沿高度、车道中线、红绿灯拓扑、限速牌乃至斑马线几何形状。一旦前方出现临时道路施工、脚手架遮挡或车道临时改道，高度依赖地图先验的车辆极易陷入定位降级甚至直接在路中央“趴窝”。

在伦敦，搞高精地图几乎是所有工程师的噩梦。这里没有凤凰城那种横平竖直的方格路网，也没有加州郊区宽阔的四车道林荫大道。伦敦的街道是由中世纪马车道与维多利亚时期的狭窄巷弄交织而成的迷宫：
*   **无标线极窄路段：** 双向道路经常被临时停靠的送货厢货挤压成单车道咽喉，极为考验驾驶者之间的眼神交汇、闪灯博弈与非言语“默契礼让”。
*   **混沌的多车道大型环岛：** 诸如象堡（Elephant & Castle）或老街（Old Street）这样的复杂多路环岛，地面几乎找不到标准车道线，车流以极高速度从多角度穿插汇入。
*   **极高熵值的混合交通流：** 穿梭在缝隙中的外卖自行车队、具有巨大视觉盲区的红色双层巴士、踩着电动滑板车呼啸而过的年轻人以及横穿马路的行人，每隔数秒就会制造一次Corner Case。

Wayve 选择了一条彻底**“无图化（Mapless）”**的道路。车辆不加载任何离线 3D 地图，AI Driver 完全依靠传感器在毫秒间理解实时拓扑几何，凭借其在大规模数据集中预训练习得的空间表征与物理常识，临场推导路权规则、博弈边界与可行使空间。

自动驾驶开源项目 comma.ai 创始人 George Hotz 曾在社交平台上尖锐点评道：
> “高精地图是一根拐杖，依赖它的公司都在自掘坟墓。现实世界时刻都在发生变化。如果你不能仅凭摄像头和本地算力在一条从未见过的街道上开起来，那你就根本不是在做自动驾驶——你只是造了一辆跑在无形轨道上的虚拟火车。”

通过拔掉高精地图的输液管，Wayve 在理论上解决了困扰自动驾驶行业十余年的跨区域规模化瓶颈：落地一座全新城市，不再需要耗时数月、耗资千万的测绘工程。

### 监管与工程黑盒：物理安全员与《2024自动驾驶法案》

剥离技术宣传的滤镜，当前在伦敦奔跑的这支 Uber-Wayve 车队不得不面对一个沉重的现实：**驾驶座上依然坐着一名持有伦敦交通局（TfL）执照的人类安全员。**

目前的试运行是在 TfL 现有的私人租车（PHV）牌照框架下开展的。从法律角度而言，安全员仍是车辆的第一责任人，他们的双手必须虚握在方向盘前数厘米处，随时准备在端到端系统遭遇极端死角时切入接管。

这种监督状态，赤裸地揭示了纯端到端系统走向真正无人化（Driverless）前必须跨越的客观藩篱：
1.  **“不可解释的黑盒”困境：** 模块化架构具备天然的故障隔离机制。如果 Waymo 突发幽灵急刹，工程师调出时序日志就能立刻排查出是视觉模型误报了障碍物，还是规划算法算错了加加速度（Jerk）。而在一个数十亿参数的端到端神经网络中，审计究竟是哪一组神经元权重导致了异常转向角，是目前机器学习领域最棘手的可解释性难题之一。
2.  **逼近极限的“9个9”：** 自动驾驶技术从 99% 表现优异的媒体试驾，走向彻底拿掉安全员所必须达到的 99.9999% 工业可靠性，中间横亘着指数级陡峭的峭壁。自动驾驶圈的技术同行们反复警惕：端到端模型极易遭受细微的分布外偏移（Out-of-Distribution shift）冲击——比如雨夜积水反射的奇异倒影、特殊喷涂的紧急救援车辆，都可能让黑盒模型突然产生灾难性的“轨迹幻觉”。
3.  **英国法规落地的真正节点：** 英国议会虽然在 2024 年 5 月正式通过了里程碑式的《自动驾驶汽车法案》（AV Act 2024），从法律层面确立了自动驾驶系统运行期间由企业承担法人责任而非安全员个人，但英国交通部（DfT）与 TfL 主导的二级立法细则、技术认证准则及安全保障框架，预计要到 2026 年底乃至 2027 年才能彻底生效执行。

Wayve 与 Uber 极为现实地将当前的监督运营阶段，打造成了一座海量真实长尾数据的吞吐工厂。在复杂市区内每一次由人类安全员触发的主动接管，都会第一时间被封装打包，作为高价值稀缺样本回流至训练流水线，用于微调 LINGO-2 的博弈策略并压力测试 GAIA-1 的世界模拟器。

### 商业账本：轻资产软件授权对抗重资产造车深渊

除了底层技术栈的更迭，Uber 与 Wayve 的联姻，更代表了自动驾驶商业范式的深层重构。

过去以 Waymo 和 Zoox 为代表的北美头部玩家，走的是一条**重度垂直整合、资本密集型的自建车队重资产模式**：
*   **庞大的 Capex 泥潭：** 自动驾驶公司需要亲自下单向车企采购定制车辆（从早期的捷豹 I-PACE 到如今向吉利定制的极氪车型），在车顶加装动辄配置高精度自研激光雷达、雷达与近30个相机的传感器硬件套件，并且自掏腰包在全球各大核心城市拿地建设高标准维保场站。在早些年，单车硬件及传感器物料清单（BOM）成本轻而易举突破 10 万美元。
*   **空驶率的经济学诅咒：** 重资产车队必须直面残酷的产能利用率波动。一旦度过早晚通勤高峰，价格昂贵的无人车只能停在路边或场站空耗折旧，抑或在郊区之间无偿进行“无效空驶（Deadhead Miles）”以重新平衡运力分布。

与此针锋相对，Uber 与 Wayve 选择构建一个**轻资产软件授权与全球运力协同生态**：

```
[ 两大商业扩展模式对比 ]

Waymo / Zoox (重资产资本密集模式):
母公司资本开支 ➔ 深度定制造车 ➔ 重度场站基建 ➔ 自营排他车队运营 ➔ 独立垂直叫车应用

Uber + Wayve (轻资产软件授权模式):
主流车企 (福特、日产等) ➔ Wayve AI Driver (基础模型软件授权) ➔ 车队管理方/个体运力 ➔ Uber 全球需求聚合网络 (超2亿月活)
```

Wayve 的定位从来不是车企或车队运营商，而是一家纯粹的基础层 AI 软件提供商。凭借软银领投、英伟达、微软跟投的 10.5 亿美元 C 轮融资底气，以及 Uber 的战略注资，Wayve 装载在福特电马上的硬件方案大量采用了符合车规的量产级平价摄像头与常规雷达，将硬件与计算平台的 BOM 成本压缩至极低水平。

而 Uber 则在这一联盟中扮演着不可替代的流量聚合底座。Uber CEO Dara Khosrowshahi 多次在公开场合直言，任何试图脱离成熟出行生态、自建闭环叫车应用的自动驾驶公司，都在严重低估冷启动流动性与波峰波谷供需平衡的难度：
> “Uber 与 Wayve 拥有相同的愿景，那就是让出行变得更好。Wayve 领先的具身智能架构在我们迈向共享、电动、自主化未来的过程中蕴藏着极大的潜力。我们非常兴奋能与 Wayve 合作，与各大汽车制造商并肩，继续将 Uber 打造为全球自动驾驶汽车的最佳承载网络。”

直接接入 Uber 的双边运力网络，让这套自动驾驶系统在投入运营的第一秒就获得了稠密的商业订单。仅在伦敦一地，就有 14 万名活跃乘客主动登记排队，其用户获取成本（CAC）近乎为零。

更重要的是，伦敦街头的福特电马只是这场全球闪击战的先头部队。Uber 与 Wayve 已经公布了进军**全球 12 个核心都会区**的宏大蓝图，其下一站扩张锁定了**2026年晚些时候的日本东京**。由于彻底抛弃了高精地图的羁绊，将整套系统从伦敦左舵路网迁移至同样左行的东京街头，Wayve 只需要利用当地真实的道路视频数据集进行模型微调与特征对齐，彻底省去了漫长的全域激光雷达激光测绘工程。

### 终局审判：软件 2.0 能否接管物理世界？

在伦敦梅费尔区（Mayfair）的维多利亚式排屋、哈克尼（Hackney）的潮流拥堵街巷与萨瑟克（Southwark）湿滑的转盘之间穿梭的那些福特电马，正在进行一场人类商业与科技史上赌注最大的实景实验。

如果 Wayve 能够伴随着英国《自动驾驶汽车法案》的全面落地，顺利拿掉安全员、实现无保留的真正无人驾驶，它将彻底坐实验证 Yann LeCun 与 Andrej Karpathy 的核心论断——**基础世界模型与端到端深度学习，才是物理世界实现完全自主智能的终极解法**。届时，耗资数百亿美元铺设的高精地图和机械规则代码库将在一夜之间沦为沉重的历史包袱，而 Uber 也将凭借即插即用的 AI 软件接口，顺理成章地将全球存量车企变为自己的无人运力代工厂。

但反过来，如果伦敦那无穷无尽的极端长尾 Corner Case 最终被证明是无约束神经网络无法收敛的黑洞——如果为了规避“不可解释的致命幻觉”，Wayve 不得不妥协加入越来越多的规则代码垫片和模块化约束层，那么，坚守在硅谷城堡深处的 Waymo，将继续捍卫其耗时二十年建立的工程学王座。

无论结局如何，至少有一点是确凿无疑的：在伦敦阴冷潮湿的细雨中，关乎自动驾驶乃至具身智能未来灵魂的终极对决，已经不再停留在幻灯片上的白板推演或加州阳光下的封闭仿真里。它正裹挟着真实的乘客，在一个接一个狂暴的现实环岛中，呼啸向前。
