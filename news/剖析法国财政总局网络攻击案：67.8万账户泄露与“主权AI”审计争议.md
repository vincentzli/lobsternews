# 剖析法国财政总局网络攻击案：67.8万账户泄露与“主权AI”审计争议

2026年8月12日，在暗网论坛PwnForums上，一个名为“ZeroBytes”的账号发布了一则出售帖。帖中售卖的是一份包含约678,438名法国公民及企业个人与财务记录的数据库。售价达数千欧元，瞬间引爆了外界对法国公共部门IT基础设施安全性的强烈担忧。这份被窃取的数据堪称法国国民生活的“精密档案”：包含参考税收收入（RFR）、家庭商数、源头扣缴个人所得税率、企业SIREN识别号，甚至还详尽记录了名下房产的建筑面积。

随着泄露细节逐步浮出水面，法国政府宏伟的数字化野心与陈旧行政网络中脆弱的安防现状之间，那道日益撕裂的鸿沟被彻底暴露。这起事件不仅惊动了法国最高层并紧急召开跨部委研判会，引发了巴黎检察院的刑事调查，更催生了一项极具争议的“自救”计划——部署主权人工智能对国家行政遗留的老旧系统进行全面安全审计。

### 隐秘的缺口

此次风暴的暴风眼是地籍数据专业服务器（SPDC）——这是通往法国土地登记系统的专业入口。该门户由法国财政总局（DGFiP）直接管辖，日常访问域名为 apexappliext.dgfip.finances.gouv.fr，是公证人、土地测量师及地方政府官员日常高频使用的系统。

根据网络安全审计报告及法国财政部随后的承认，黑客“ZeroBytes”攻破这道关卡并未动用任何高深的“零日漏洞”（zero-day exploit）。相反，他们仅仅使用了窃取来的凭证——这套凭证属于一名财政总局员工及一家获得授权的第三方合作伙伴。凭借这一“合法”身份，攻击者轻松绕过了该门户的多重身份验证（MFA）协议。

比漏洞本身更令人震惊的，是其漫长的潜伏期与行政体系的迟钝反应。财政总局的内部安全监测其实早在2026年6月下旬就检测到了异常访问，当时技术人员切断了非法会话，并误以为危机已被成功化解。然而，在随后的近两个月里，法国政府对其间67.8万名纳税人数据已被悉数打包拖走的事实一无所知。直到8月12日，当整份数据库被明码标价挂在暗网论坛PwnForums上售卖时，官方才惊觉数据早已失窃。

“这是一个典型的‘检测滞后’案例，”一位为法国公共机构提供安防咨询的匿名网络安全专家指出，“切断非法连接很容易，但要进行深度的网络取证，查清黑客到底拉走了多少数据，需要投入极大的资源。而对于被沉重‘技术债’（technological debt）压得喘不过气来的公共行政机构而言，这类工作往往不在他们的优先日程表上。”

### 贝尔西的抉择

失窃数据的公开曝光，逼迫法国政府仓促应对。2026年8月17日，法国总理塞巴斯蒂安·勒科尔尼（Sébastien Lecornu）紧急召开跨部委研判会议，协调全国应对措施。巴黎检察官办公室随即正式立案展开司法调查，并将案件移交反网络犯罪办公室（OFAC）具体侦办。

次日（8月18日），公共行动和账目部部长大卫·阿米埃尔（David Amiel）与财政总局局长阿梅莉·维尔迪耶（Amélie Verdier）在财政部大楼（贝尔西）举行联合新闻发布会。阿米埃尔向公众公开致歉：“是的，我们深表歉意，因为发生这样的事情对法国民众而言是无法忍受的（Oui, nous nous excusons, parce que ce qui est arrivé est insupportable pour les Français）。”维尔迪耶在会上证实了第三起——尽管规模小得多——发生在“无人继承财产”（successions vacantes）门户上的数据泄露事件，但她强调其波及范围远小于SPDC泄露案。

为了亡羊补牢，法国政府宣布了一项强制令：所有公共部门IT系统及其授权的第三方合作伙伴，必须在2026年12月31日之前部署更为严格的双因子认证协议。

然而，发布会上最引人注目的，是阿米埃尔提出的一项利用先进人工智能模型审计国家庞大IT基础设施的计划。政府宣布将与法国本土的“主权AI”企业——尤其是Mistral AI——展开合作，对公共网络进行攻击性审计与漏洞扫描。当被问及该计划是否会引入美国供应商OpenAI时，阿米埃尔态度决绝地给出了否定回答：“这排除OpenAI。”

这一举措被包装为对“技术主权”的捍卫，旨在确保公共部门IT系统敏感漏洞分布图不被暴露给受美国《云法案》（Cloud Act）等跨境立法管辖的外国实体。

### 舆论场的反弹

在 Reddit 论坛 r/france 和 r/cybersecurity 上，法国 IT 从业者与普通网民的反应充斥着愤怒与黑色幽默。信息披露的严重滞后成为舆论讨伐的焦点。

“他们在6月份发现了入侵，关上了门，然后就开开心心地去度暑假了，以为万事大吉，”一位 r/france 用户嘲讽道，“最后居然是靠黑客在论坛上发帖叫卖，官方才知道数据被偷了，这简直是官僚式业余水平的巅峰。”

在 r/cybersecurity 论坛上，讨论则直指法国公共 IT 系统积重难返的体制性顽疾。评论者们纷纷吐槽，在连最基础的网络安全“卫生习惯”都未能普及的情况下，政府却急于推行高大上的 AI 审计，这无疑是极大的讽刺。

“他们在大谈部署 Mistral AI 去审计老旧数据库，却连在第三方合作伙伴门户上强制执行有效的多重身份验证（MFA）都做不到，”一位系统管理员在一篇高赞帖子里写道，“你不需要机器学习来告诉你，在没有强制性、不可绕过的硬件 MFA 的情况下共享凭证，本身就是一场灾难。”

许多留言还揭示了财政总局及其他部委内部根深蒂固的 IT 人才招募危机。公共部门极度依赖外部承包商，这被普遍认为是公务员薪资过低导致的直接恶果。在法国，公共行政部门的一名初级 Java 开发人员的起薪，通常比私营市场的均价低 30% 到 40%。这导致政府的 IT 项目背负着沉重的“技术债”（dette technologique）——代码陈旧、人员流失率高，且过度依赖外部咨询顾问。而这些外部人员，往往无法受到与内部编制人员同等强度的安全审查。

随着巴黎检察官办公室对黑客“ZeroBytes”的调查持续深入，法国财政总局正面临着一项极其艰巨的任务：他们必须向 67.8 万名个人和企业发送通知，告知其财务隐私数据已流入黑市。对于法国政府而言，这次惨痛的教训是一个警示：在网络战时代，技术主权无法仅靠与 AI 巨头联姻来买到；它必须建立在最基础的网络安防细节，以及合理定价的公共 IT 人才队伍之上。
