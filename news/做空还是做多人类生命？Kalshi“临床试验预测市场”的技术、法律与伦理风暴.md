# 做空还是做多人类生命？Kalshi“临床试验预测市场”的技术、法律与伦理风暴

2026年7月16日，预测合约交易所 Kalshi 联手 AI 数据情报机构 AppliedXL，试点推出了一套全新的二元事件合约（binary event contracts）。该合约允许用户直接针对临床试验后期结果以及 FDA 的监管审批进行交易。通过将药物研发的成败转化为散户和机构资金博弈的金融合约，Kalshi 试图打破长期笼罩在生物医药行业的“信息孤岛”。

从吉利德与 Arcellx 联合开发的治疗多发性骨髓瘤的 anito-cel，到 Summit Therapeutics 的肺癌明星药 ivonescimab，再到 AriBio 针对阿尔茨海默病开展的 POLARIS-AD 3期临床试验——首批试点挂牌了十余款备受瞩目的候选药物。在硅谷精英和风险投资人眼中，这是罗宾·汉森（Robin Hanson）“决策市场”理论的终极落地——一个去中心化、实时的公共概率信号；但在生物伦理学家、医学研究者及各州监管者看来，这无异于对人类临床试验科学严谨性的直接挑衅。

### 对赌背后的数据工程学
判定一款候选药物是否“成功”，远比统计一场球赛的比分复杂得多。为了构建一个防操纵、高鲁棒性的自动清算层，Kalshi 与 AppliedXL 合作研发了一套自动化数据决议流水线。

这套清算机制高度依赖于与美国联邦数据库的程序化对接。在交易启动前，流水线会首先调用 ClinicalTrials.gov 的 API (v2)，锁定试验的初始参数。具体而言，系统通过解析 `/api/v2/studies/{nctId}` 接口返回的 JSON 数据，精确定位到试验的主导终点（primary outcomes）：

```json
"protocolSection": {
  "outcomesModule": {
    "primaryOutcomes": [
      {
        "measure": "PFS (Progression-Free Survival)",
        "timeFrame": "Up to 24 months"
      }
    ]
  }
}
```

这一特定指标的英文原始表述将被直接写入合约的清算条款中。一旦申办方（Sponsor）将最终数据上传至 `resultsSection`（特别是 `outcomeMeasuresModule`），或 FDA 发布官方监管动作，合约便会触发清算。对于 FDA 审批市场，清算引擎会实时监控 FDA 药品审评与研究中心（CDER）的数据库，爬取官方批准信（approval letters），或直接解析 FDA 咨询委员会（AdComs）的公开投票结果。

为防范“抢跑”（front-running），Kalshi 限制了交易准入条件：仅允许已完全完成患者招募的临床中后期试验挂牌。此外，交易所强制推行雇员身份验证，严禁临床试验研究员、制药公司员工、FDA 监管官员以及参与试验的患者进入市场交易。

### 伦理风暴与“临床等效性悖论”
即便设置了上述防火墙，医学研究界依然报以强烈的反对。批评的核心指向了生物伦理学中的“临床等效性悖论”（equipoise paradox）。

随机对照临床试验的伦理前提是：科学界对于“治疗组（活性药物）”与“对照组（安慰剂）”究竟哪一个更优，必须存在真正的学术不确定性。在试点设计阶段接受过咨询的麦吉尔大学生物伦理学教授乔纳森·基梅尔曼（Jonathan Kimmelman）警告称，这存在深层的结构性危害：“如果一个预测市场变得高度精准，将某种药物的成功概率定价在 95%，我们将面临巨大的伦理危机。当公开的金融市场已经宣告了‘赢家’，临床研究员还能在违背良知的情况下，继续让患者加入安慰剂对照组吗？”

此外，批评者认为，庞大的资金博弈不可避免地会污染临床试验过程中的行为。就算研究员和患者被禁止交易，他们也无法对市场噪音“免疫”。如果某款药物的合约价格跌到了 0.1 美元（暗示仅有 10% 的成功率），活性药组的患者可能会因为丧失信心而退出试验，研究员也可能失去继续收集数据的动力。

KKH 创始人兼 CEO Kimberly Ha 对此项结构性激励表示担忧：“如果围绕临床试验结果建立预测市场，显然会引发关于动机扭曲和滥用风险的质疑。”开放科学中心（Center for Open Science）执行主任布莱恩·诺塞克（Brian Nosek）也表达了类似的观点：“以盈利为目的的开放式预测市场，会给科学研究带来实质性风险。”

尽管传统药企和机构此前也常用私人衍生品来对冲研发风险，但将赌注搬到流动性极高的散户交易所，彻底改变了博弈规则。知情人士——例如能够看到未盲态中期安全性及有效性数据的“数据监察委员会”（DMC）成员——手中掌握着价值数百万美元的内幕信息。即使有雇员验证机制，如何封堵通过白手套交易者进行的“台面下”内幕信息勾兑，依然是 Kalshi 合规引擎难以逾越的鸿沟。

### 司法内战：联邦前置管辖权与各州博弈
这一 markets 的上线，加速了联邦商品监管机构与各州司法权力之间的剧烈碰撞。

就在今天（2026年7月31日），纽约州州长凯西·霍楚尔（Kathy Hochul）与总检察长詹乐霞（Letitia James）正式起诉 Kalshi，指控该平台运营非法、无牌照的赌博业务。纽约州声称，Kalshi 在未获得纽约州博彩委员会许可的情况下擅自运营，并使包括 21 岁以下未成年人在内的公民面临掠夺性的金融风险。州政府正寻求永久禁令、没收违法所得，并处以平台获利金额三倍的民事罚金。

Kalshi 的法律防御建立在“联邦预占原则”（Federal Preemption）之上。作为受美国商品期货交易委员会（CFTC）监管的指定合约市场（DCM），Kalshi 坚称，根据《商品交易法》（CEA），联邦监管权高于各州的博彩法律。

然而，各州法院正逐步推翻这一说辞：
* **纽约州的重挫**：2026年7月初，纽约南区联邦地方法院法官 Analisa Torres 驳回了 Kalshi 阻止州政府执法的紧急禁令申请，裁定《商品交易法》并未完全排除州政府对事件合约的治安管辖权。这为今天的起诉扫清了障碍。
* **密歇根州的冲突**：2026年6月，密歇根州巡回法院发出临时限制令（TRO）叫停 Kalshi 的运营。戏剧性的是，CFTC 在 7 月强势介入，发布联邦指令要求 Kalshi 必须履行其挂牌的合约——这导致州法院与联邦监管机构陷入了直接的宪法对峙。
* **巡回法庭的分歧**：尽管第三巡回法庭在 2026 年 4 月裁定联邦法律优于新泽西州的博彩法，但第六巡回法庭在 7 月底听取了俄亥俄州和田纳西州的上诉辩论。这几乎注定了各巡回法庭之间将产生司法分歧，并最终迫使美国最高法院介入裁决。

### 硅谷共识：去中心化的真理寻索
与学术界和政界的警惕不同，硅谷的反应截然相反。知名风投家和科技创始人纷纷为 Kalshi 发声，将法律监管的阻力视为建制派的“看门狗”行为。

预测市场的死忠拥趸巴拉吉·斯里尼瓦桑（Balaji Srinivasan）认为，像 Kalshi 这样的平台是“去中心化真理寻索”的必要工具，能绕过大药企被资本公关粉饰的官方口径。同样，经济学家亚历克斯·塔巴罗克（Alex Tabarrok）长期指出，FDA 缓慢的审批速度造就了无数被延误创新的“隐形墓地”；而在他看来，预测市场能为生物制药管线引入急需的市场纪律和定价效率。

然而，随着法律与伦理的战火愈演愈烈，核心的考量依然未变：预测市场究竟能成为可靠的公共概率指标，还是会彻底瓦解人类临床研究所需的脆弱信任？如果临床数据本身的真实性与严谨性已被金融市场的利益诱惑所侵蚀，那么所谓的“群体智慧”，最终不过是构建在沙滩上的空中楼阁。
