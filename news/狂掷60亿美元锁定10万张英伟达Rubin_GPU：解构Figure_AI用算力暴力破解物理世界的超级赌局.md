# 狂掷60亿美元锁定10万张英伟达Rubin GPU：解构Figure AI用算力暴力破解物理世界的超级赌局

在人形机器人进化的关键节点上，硅谷长期分裂为两大针锋相对的技术宗派。

一方是坚守硬核物理世界的经典机器人学家与机械工程师。在他们眼中，物理现实是一个由非线性接触动力学、热耗散、齿轮背隙（Backlash）以及严苛驱动器物理特性主宰的残酷领域，任何轻视机械本体的算法终将撞墙。另一方则是极致的“算力扩增主义者”（Compute Maximalists），他们坚信硬件机械早已是成熟的商品化货架件，所谓通用物理智能（General-Purpose Physical Intelligence），本质上纯粹是多模态 Token 吞吐量、模型参数容量与算力暴力扩展（Brute-Force Scaling）的代数函数。

如今，人形机器人独角兽 Figure AI 以前所未有的资本体量，为后一种理论压上了整个赛道有史以来最大的一笔注码。

通过与超大规模 AI 云基础设施提供商 Nscale 达成的多年期战略合作，Figure 敲定了一笔初始金额达 35 亿美元、协议总额可扩展至逾 60 亿美元的算力采购协议。凭借这份合约，Figure 锁定了多达 10 万张基于英伟达下一代 **NVIDIA Vera Rubin** 架构构建的高性能 GPU 集群。这批预计将于 2027 年下半年在 Nscale 位于得克萨斯州巴斯托（Barstow）的超高密度数据中心分阶段通电并网的算力底座，宣告了具身智能（Embodied AI）在融资规模、系统架构和训练范式上的质变。

根据协议细则，Nscale 将作为 Figure 的优先云基础设施提供商，并持有 Figure 的部分股权。更有戏剧性的是一个“自我复制”式工业闭环：Figure 的双足机器人将被直接部署到 Nscale 的数据中心现场，亲自承担高密度 GPU 机柜的机械组装、机架维护和物理物流任务——换言之，这批机器人物理本体的双手，将负责搭建和维系正在训练其大脑的超算集群。

“阻碍我们训练物理基础模型 Helix 的核心瓶颈，归根结底是数据与算力，”Figure 创始人兼 CEO 布雷特·阿德考克（Brett Adcock）在宣布该交易时直言不讳，“与 Nscale 的合作为我们提供了充足的算力跑道，推动 Helix 持续扩展，从而解锁媲美人类的灵巧操作与物理智能。”

英伟达创始人兼 CEO 黄仁勋对此报以极高评价，将其视作其推崇的“工业飞轮”终极落地：“这一合作彻底激活了机器人飞轮效应——在 Nscale 云端基于英伟达 Vera Rubin 架构训练 Figure 的模型，在英伟达 Isaac Sim 中完成大规模仿真验证，并最终部署到搭载英伟达端侧芯片的 Figure 机器人本体上。”

然而，在令人眩晕的数十亿美元资本支出背后，一场触及具身智能技术底层的风暴正在酝酿：由 10 万张 Rubin GPU 构筑的百亿亿次级（Exaflop-scale）算力，真的能够填平横亘在虚拟与现实之间的“Sim-to-Real（仿真到真实）鸿沟”吗？抑或是 Figure 正在试图用自回归 Transformer 和合成域随机化（Domain Randomization），去强行征服一个根本无法被纯算力降维打击的物理真实？

### 解构阿德考克的技术假设：驱动机械 vs Token 吞吐量

数十年来，人形机器人的崩溃往往归咎于机械本体的物理缺陷：无刷直流电机（BLDC）推重比不足、摆线针轮或谐波减速器的传动间隙与背隙超标、串联弹性驱动器（SEA）的顺应性控制迟滞，以及高负载高扭矩输出下的严重发热降频。

但在阿德考克主导 Figure 02 以及下一代 Figure 03 的工程实践中，他确立了一个核心假设：**硬件机械的动态性能已经越过了通用操作的可用阈值。**

当自研一体化摆线执行器能够提供超过 150 Nm/kg 的扭矩密度，当具备 16 个自由度、集成测力传感单元与亚毫米级高精度编码器的灵巧手成为现实，机械本体便不再是决定机器人能力上限的短板。

在阿德考克的技术蓝图里，真正卡住人形机器人演进喉咙的，是一个纯粹的信息论瓶颈：**预训练阶段的多模态 Token 吞吐率，以及端侧闭环推理的高频响应速率。**

```
[ 经典机器人控制范式 ]
传感器输入 -> 运动学状态估计 -> 非线性 MPC / 二次规划 (QP) 求解器 -> 轨迹执行 (经典 PID 控制)
   * 痛点：极度脆弱、专机专用、工程维护代价极高、跨任务泛化能力几乎为零。

[ 物理具身基座模型范式 (Helix) ]
多路 RGB-D 视频流 + 关节本体感知 + 触觉矩阵 -> 高带宽 VLA Transformer -> 动作输出空间 (连续扭矩 / 关节增量)
   * 优势：能力随算力（FLOPs）与动作 Token 规模严格单调递增，具备跨硬件形态的泛化潜力。
```

对比大语言模型（LLM），自回归架构处理离散文本 Token 的吞吐量通常在每秒 30 到 100 个 Token 之间；而具身视觉-语言-动作（VLA）模型，则运行在极高带宽的多源连续信号严苛约束之下：
1. **多视角高帧率视觉流：** 4 至 6 路同步的 1080p RGB-D 摄像头信号，以 30–60 Hz 频率采集，带来高达 ~1.2 GB/s 的原始感官数据吞吐；
2. **关节本体感知状态：** 40 多个自由度的关节位置、角速度、电机母线电流与实时扭矩反馈，刷新率高达 200 Hz 至 1 kHz；
3. **高密度微触觉矩阵：** 覆盖在指尖与手掌表面的微型触觉传感阵列，以 100 Hz 持续捕捉亚毫米级法向压力、剪切力及微滑移信号；
4. **高频动作预测空间：** 连续 6 自由度末端执行器轨迹增量、夹爪抓握力，以及全身控制（WBC）的关节力矩，要求模型在低于 20 毫秒的超低延迟内完成闭环推断。

当这一切被统一编码为连续的多模态 Token 序列，想要让基座模型学会在数百万个极端长尾工况中完成长时程操作与复杂地形直立行走，每个训练 Epoch 都要消化海量时空同步的多模态 Token。缺乏支撑数百 Exaflops 低精度浮点计算的超大规模算力集群，模型的上下文窗口与参数规模将迅速遭遇扩展天花板。

### “Helix”技术管线：高频 VLA 与端到端触觉融合架构

Figure 这场算力豪赌的技术核心，是其代号为 **Helix** 的自研具身 VLA 基座模型。

```
+---------------------------------------------------------------------------------------------------+
|                                     HELIX 基座模型架构流程图                                       |
+---------------------------------------------------------------------------------------------------+
|   [多目 RGB-D 视频流]             [自然语言任务指令]               [高密度微触觉传感阵列]           |
|            |                               |                                 |                    |
|            v                               v                                 v                    |
|    时空视觉编码器                  任务指令分词器                   连续触觉 Transformer 模块      |
|            |                               |                                 |                    |
|            +-------------------------------+---------------------------------+                    |
|                                            |                                                      |
|                                            v                                                      |
|                    +-----------------------------------------------+                              |
|                    |          低频语义推理主干 (5-10 Hz)           |                              |
|                    |        长时程任务规划与操作空间可供性解析     |                              |
|                    +-----------------------------------------------+                              |
|                                            | 任务隐空间表征 (Latent Task Embedding)               |
|                                            v                                                      |
|                    +-----------------------------------------------+                              |
|                    |     高频动作扩散/流匹配动作头 (50-200 Hz)     | <--- 实时本体感知输入 (500Hz)|
|                    |              连续电机动作实时控制             |                              |
|                    +-----------------------------------------------+                              |
|                                            |                                                      |
|                                            v                                                      |
|                          目标关节位置 / 速度 / 扭矩控制指令                                       |
+---------------------------------------------------------------------------------------------------+
```

传统的具身模型大多采用松散解耦架构——由低频视觉语言模型（VLM）输出离散的高层文本伪代码，再交由传统的底层运动规划器执行。Helix 彻底摒弃了这一路线，转而采用紧耦合的分层物理 Transformer 架构：

1. **双频分层解耦架构（Dual-Frequency Hierarchical Decoupling）：**
   * **低频语义推理主干（5–10 Hz）：** 一个拥有数十亿参数的大规模自回归 Transformer，负责吞吐编码后的视频时序帧与自然语言指令，执行环境三维几何分解、操作可供性（Affordance）提取以及动态目标时序追踪。
   * **高频动作流匹配头（50–200 Hz）：** 以低频语义主干输出的潜在表征为条件指导，动作头采用低延迟生成式扩散（Diffusion）或流匹配（Flow Matching）策略。该模块直接吞入 500 Hz 的实时关节本体感知数据（编码器角度、IMU 线加速度等），以滚动时域方式（Receding Horizon）连续预测输出分块的平滑运动轨迹。

2. **端到端微触觉感知融合：**
   当前绝大多数 VLA 模型在精细装配中失效的根源在于对视觉的过度依赖。在插拔线缆、柔性线束布置或抓取光滑形变物体等强接触任务中，末端执行器和机械臂往往在接触发生的瞬间挡死摄像头视野。Helix 引入了专用的连续触觉 Transformer 层，直接摄取高分辨率压力传感矩阵。这些触觉隐层 Token 无需经过复杂的上层视觉编码器折返，而是直接与底层动作头进行交叉注意力计算，在不到 10 毫秒内触发类似人类脊髓神经反射级的抓握力调整与防滑稳定。

3. **跨形态（Cross-Embodiment）仿真预训练：**
   Helix 在统一的标准化坐标空间中训练，将异构硬件的运动学树和驱动器力矩极限映射到共享的隐式动作表征空间中。因此，Helix 不仅吸收 Figure 02 和 03 的高保真遥操作数据，还能在预训练阶段直接吞吐成千上万个模拟机械臂（如 UR5、Franka Research 3）以及双臂平台的仿真操作数据。

### 英伟达“机器人飞轮”在 Vera Rubin 架构上的落地

部署在 Nscale 得州巴斯托基地的 10 万张 GPU，是英伟达具身智能全栈软硬件生态首次在超大规模数据中心级别落地运行：

```
[ Nscale 得州巴斯托超高密度数据中心：10 万张 Vera Rubin GPU 集群 ]
        |
        |--- 模型预训练：Helix 具身 VLA 基座模型 (FP4 / FP8 Tensor Cores)
        |--- 物理仿真：NVIDIA Isaac Sim / Isaac Lab (基于 Omniverse PhysX 5)
        |       * 并行运行数百万个物理仿真环境
        |       * 极端域随机化 (摩擦力、质量分布、传感器噪声)
        v
[ 模型轻量化编译：TensorRT-LLM / TensorRT Edge ]
        v
[ 机器人本体嵌入式算力 (NVIDIA Jetson/Drive Thor SoC) ]
        |
        |--- 端侧极速推理：<20ms 控制闭环，功耗严格压制在 150W 以内
        |--- 边缘长尾故障拦截 -> 真实世界车队遥测数据回传
        v
[ 遥测回传与 Figure "Index" 众包遥操作真机数据采集平台 ]
        |
        +---- 高价值数据重新注入 Nscale 算力集群训练 (飞轮闭环运转)
```

#### 硬件基石：NVIDIA Vera Rubin 超算架构
预计将于 2026 至 2027 年推向数据中心市场的 Vera Rubin 架构，是 Blackwell 之后的下一代算力旗舰：
* **Vera CPU：** 针对密集多模态数据设计的定制 Arm 架构高 IPC 处理器，旨在解决多路高带宽超高清视频与传感器队列吞吐至 GPU 显存时的管线停顿（Pipeline Stall）难题。
* **Rubin GPU：** 全面集成下一代 **HBM4** 高带宽内存，单芯片内存带宽突破 10 TB/s 大关，并原生支持更低比特的微精细数据格式（FP4 与 NVFP4）。
* **NVLink 6 高速互联：** 提供单卡最高 3.6 TB/s 的双向互联带宽，使得数百亿至数千亿参数级别的 VLA 模型能够在全液冷机柜超级计算单元内实现大跨度的张量并行与模型并行切分。

#### 仿真引擎：Isaac Lab 极端域随机化
纯靠真机遥操作采集具身数据不仅成本极其高昂，物理时间更无法压缩。Figure 选择倚重 NVIDIA Isaac Sim 与 Isaac Lab，在数万张 Rubin GPU 上并发运行数百万个高拟真虚拟环境。

为击穿从虚拟跨越到现实的 Sim-to-Real 障碍，其仿真管线施加了极其严苛的**极端域随机化（Extreme Domain Randomization）**：
* **物理动力学随机摄动：** 静摩擦与动摩擦系数在大范围（$\mu \in [0.1, 1.8]$）内随机扰动，叠加恢复系数、构件质量分布偏差、质心偏移以及执行器背隙误差；
* **光线追踪视觉随机化：** 利用 Omniverse RTX 渲染管线，随机调制打光环境、材质反射、摄像头内参畸变、运动模糊与环境光遮蔽；
* **传输延迟动态注入：** 针对控制链路注入 10 至 50 毫秒不等的抖动、丢包与传感器延迟，迫使策略网络演化出对本体硬件中断极度鲁棒的运动抗扰能力。

#### 边缘量化与低功耗部署
一个千亿级参数的模型绝不可能在散热功耗仅有 150W 至 250W 的双足机器人本体上直接全精度运行。飞轮运转的最后一步，是利用 NVIDIA TensorRT 对 Helix 的底层控制策略进行图优化与 FP4 深度量化，将其压进机器人本体搭载的双 SoC 算力单元（如 NVIDIA Jetson Thor 或 Drive Thor），在完全离线无网的环境下实现 50 Hz 强实时确定性闭环控制。

### 路线大激辩：算力暴力美学 vs 物理接触数据之墙

尽管 Figure 与 Nscale 构筑的商业叙事极具视觉冲击力，但在全球顶尖 AI 学者与机器人学家眼中，关于“算力到底能否彻底解决物理智能”的争鸣正日趋白热化。

#### 算力与仿真扩张主义阵营
力挺 Figure 路线的学者坚信，机器人学正在经历其迟来的“萨顿苦涩教训（Sutton's Bitter Lesson）”时刻——在 AI 演进的历史上，所有试图依赖人类领域先验与精巧手工工程规则的方法，最终都会被通用的高扩展性算法与暴力计算碾得粉碎。

英伟达通用具身智能实验室（GEAR）负责人范麟熙（Jim Fan）博士曾在社交平台上明确论证这一范式：
> “机器人的通用基座模型绝不可能建立在真机运行小时数之上。现实世界中的真机遥操作永远无法被暴力扩展到数万亿 Token 的数量级。通向通用物理 AI 的唯一坦途，是吞吐极大规模、高并行度的物理仿真（每秒推演数百万个物理状态步），结合网络规模的被动视频预训练。一旦模型从海量互联网视频中理解了直觉三维物理与视觉语义，再注入少量的具身对齐数据就足以完成现实泛化。”

Nscale 首席执行官乔什·佩恩（Josh Payne）在签约现场同样亮明立场：
> “物理智能是 AI 的终极前沿。正如万卡集群的算力扩展激发出大语言模型的逻辑推理一样，百亿亿次级别的计算密度即将激发人形机器人的精细灵巧操作能力。Figure 拥有前沿的硬件与雄心，而 Nscale 正在为其锻造行星级的算力引擎。”

#### 数据之墙与物理接触怀疑论阵营
但在硬币的另一面，一众泰斗级学者和经典机器人专家纷纷发出警告：现实世界的非线性物理交互，根本无法通过看视频和合成模拟来完全化解。

Meta 首席 AI 科学家、深度学习先驱杨立昆（Yann LeCun）对使用自回归 VLA 控制连续物理动作表达了强烈抨击：
> “在连续物理空间中利用自回归架构来逐个预测动作 Token，在数学上存在根本性缺陷。真实物理世界是连续的、不完全可观测的，并且充斥着细微的不确定性。像 LLM 那样逐个生成运动动作 Token，必然导致不可逆的误差累积与灾难性漂移。如果你的架构中没有一个显式的、非生成式的联合嵌入预测架构（JEPA）世界模型，把 10 万张 GPU 砸在自回归动作生成上，纯粹是用真金白银撞向概念南墙。”

iRobot 与 Rethink Robotics 联合创始人、MIT 荣誉退休教授罗德尼·布鲁克斯（Rodney Brooks），则毫不留情地讽刺了过度迷信仿真的狂热：
> “仿真系统总是注定会‘成功’。在模拟环境里，所有数学规则都是由人写死的，机器人学会的不过是如何利用仿真器中的数学近似漏洞投机取巧。但在现实世界中，机械轴上的一块机油污渍、磨损密封圈带来的非对称摩擦、铝制关节在持续运转下的热膨胀、随机缠绕的柔性线缆……这些非线性、不可微的真实物理细节一塌糊涂。你不可能用合成数据算出来真实的摩擦系数。具身智能在替代哪怕一条产线上的普工之前，就会先撞上一堵坚硬的物理数据之墙。”

加州大学伯克利分校副教授、Physical Intelligence（π0）联合创始人谢尔盖·莱文（Sergey Levine）同样指出了具身数据与语言数据的鸿沟：
> “语言与物理操作最本质的区别在于：语言是人类交流的产物，天然高度凝练着密集语义；而机器人控制则是受物理力学支配的硬性交互。你无法通过观看 YouTube 视频去‘看’到力的分布。你可以把拧螺栓的高清视频看上一百万遍，但视频永远不可能告诉你把螺纹拧松所需要的那一瞬间峰值扭矩是多少。物理 AI 真正渴求的是高密度的‘动作-力矩’数据，而现实世界中这类高质量多模态交互数据的稀缺程度令人发指。”

### 战略分流：Figure AI、特斯拉 Optimus 与波士顿动力

Figure 对 Nscale 算力的天量押注，标志着当前人形机器人三大巨头在演进路线上已走向彻底的战略分流：

| 战略维度 | **Figure AI** (Helix / Nscale) | **Tesla Optimus** | **波士顿动力** (Atlas Electric) |
| :--- | :--- | :--- | :--- |
| **算力获取模式** | 绑定超大规模云服务商（Nscale，最高60亿美元，10万张英伟达 Rubin GPU） | 垂直自研与全内化架构（Tesla Dojo 超算 + 内部自建大规模英伟达集群） | 依托产业母公司（现代汽车集团）+ 高校及科研机构云端联盟 |
| **模型控制架构** | 端到端具身 VLA 基座模型（Helix），采用高低频语义/动作双频解耦 | 端到端深度神经网络，技术架构深度复用并演进自 FSD 纯视觉感知到动作映射管线 | 经典混合范式：模型预测控制 (MPC) + 全身控制 (WBC) + 局部强化学习 (RL) |
| **数据采集哲学** | 虚拟合成 Isaac Sim（极致域随机化）+ "Index" 众包遥操作真实数据回流 | 大规模内部自建遥操作车队采集 + 上百万辆特斯拉在途车辆被动视频特征迁移 | 经典刚体动力学建模、轨迹优化理论指导、针对特定任务目标的小规模模仿学习 |
| **执行器工程理念** | 商业成熟方案演进：定制高转矩摆线减速驱动一体化关节，标准化模块本体 | 极高自研垂直整合：定制化高功率密度旋转与直线执行器、自研多自由度触觉手 | 工业级超高动态性能定制电驱关节、极端动态响应范围、高爆发峰值力矩模组 |
| **商业落地上限** | 工业场景试点铺开（宝马斯巴坦堡工厂、Nscale 超级数据中心机柜物流与运维） | 特斯拉自有超级工厂产线内化（优先在电池装配、汽车总装车间形成内部替代） | 汽车工业物流（现代制造基地）、重工场景巡检、高机动性复杂动态非结构化操作 |

* **特斯拉的垂直一体化壁垒：** 马斯克对第三方云提供商保持着天然的冷漠，Optimus 完全依托特斯拉全栈自研的算力闭环。特斯拉的核心护城河在于庞大且受控的遥操作工程师团队，以及从 FSD 全自动驾驶演进出的视觉轨迹生成能力。更致命的是，特斯拉能够在其全球超级工厂的汽车产线上以零商业摩擦成本向机器人注入真实的制造业工况。
* **波士顿动力的控制论严谨：** 拥有数十年控制论积淀的波士顿动力，从未盲目相信不可控的黑盒神经网络。全新全电动 Atlas 虽然在非结构化地形运动中大幅融合了强化学习策略，但系统最底层的安全冗余、平衡稳定与极限防护，依然牢牢锚定在确定性的高频 MPC 与动力学约束求解器上。在重工业和高危作业场景中，完全端到端的神经网络所伴生的小概率但灾难性的随机漂移，是他们绝对无法承受的工程代价。

### 终局裁决：物理真实世界里的豪赌

Figure 与 Nscale 签下的 60 亿美元超级算力订单，其意义早已超越了一笔单纯的云服务硬件交易。它是深度学习缩放定律（Scaling Law）被强行推入真实物理世界后，所迎来的一场极为残酷的工业级压力测试。

如果布雷特·阿德考克的理论被最终验证——如果极高频的 Token 吞吐、10 万张 Rubin GPU 的恐怖算力配合行星级的物理仿真，真的能够催生出通用物理策略的“涌现”，那么 Figure 就击穿了困扰人工智能半个世纪的“莫拉维克悖论”，一跃成为物理世界劳动力市场的通用操作系统定义者。

但反过来，如果真实的物理世界拒绝被过度数字分词化——如果微观接触动力学、机械摩擦滞后、以及不可预测的刚柔形变，必须要依靠数以亿计的真机物理交互与物理力觉反馈才能闭环，那么 Figure 在得克萨斯巴斯托荒原上通电的 10 万张液冷 GPU，就将化作机器人技术史上最昂贵的一场“算力虚火”。

具身智能的角斗场早已脱离了单纯的算法原型验证。在下一个五年，衡量它的单位将不再只是论文与 Demo，而是以兆瓦计的电力负荷、以万平米计的数据中心厂房，以及一座座轰鸣运转的液冷超算集群。
