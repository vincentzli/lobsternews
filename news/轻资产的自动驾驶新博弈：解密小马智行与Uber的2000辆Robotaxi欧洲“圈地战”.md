# 轻资产的自动驾驶新博弈：解密小马智行与Uber的2000辆Robotaxi欧洲“圈地战”

L4级自动驾驶的商业化落地，正在迎来一场深刻的结构性范式转移。

多年来，自动驾驶（AV）行业一直被割裂为两大阵营：一类是以谷歌Waymo为代表、背负沉重资本的垂直一体化流派；另一类则是传统主机厂主导的硬件优先流派。然而，小马智行（Pony.ai）与出行巨头Uber最新达成的深度战略合作，打破了这一既有格局。双方计划在欧洲和中东地区投放超2000辆Robotaxi。这向行业证明：走向全球化规模扩张的破局之道，或许正隐藏在一种三方联动的“轻资产”落地模式之中。

通过将小马智行的L4级软件栈、Uber庞大的全球流量池以及本地车队合作伙伴（消化硬件资产开支）相结合，该联盟试图绕过重资产持有的资金泥潭，同时规避欧洲极为割裂的监管迷宫。不过，正如其克罗地亚萨格勒布（Zagreb）的试点项目所展现的那样，这一策略在实际执行中，必须在工程妥协、监管博弈以及本土化技术调优之间寻求微妙的平衡。

---

### 财务底盘：小马智行2026年第二季度的爆发式增长

在这场激进扩张的背后，小马智行刚刚披露的财务业绩提供了坚实的底气。2026年8月18日，小马智行发布了2026年第二季度财报。财报显示，公司单季度总营收达3620万美元（同比增长68.8%）。这一增长的核心引擎，源于**Robotaxi服务收入同比爆发式增长691.2%，达到1210万美元**。其中，付费乘车服务的收入同比增长更是达到了惊人的849.3%。

目前小马智行在路测及运营的活跃车辆为1975辆，年底目标直指3500辆以上。在此基础上，公司已锁定超过4000辆的海外车辆意向订单。而此次与Uber达成的超2000辆Robotaxi的合作，无疑是其海外版图的关键支撑。这释放出了一个明确信号：小马智行已不再局限于中国本土市场，而是通过向第三方输出资金成本的方式，在全球范围内以轻资产姿态实现规模化扩张。

### 三柱支撑：去中心化的运营模式

为了在不同司法管辖区内快速扩张且不被高昂的车辆折旧压垮，Uber与小马智行构建了一个去中心化的“三柱支撑”运营模式：

1. **第一柱：L4级技术栈（小马智行）**：提供其第七代（Gen-7）自动驾驶系统。该系统集成了多传感器融合方案（包括固态激光雷达、摄像头及毫米波雷达），并适配于标准化车型平台（如中国制造的极狐阿尔法T5电动SUV）。
2. **第二柱：流量与调度引擎（Uber）**：通过“Uber Autonomous Solutions” API接口，处理车辆呼叫、用户获取、路线优化、账单结算及安全调度，将自动驾驶行程无缝接入其全球2亿月活跃用户网络。
3. **第三柱：本地车队运营商（如Verne）**：由本地运营伙伴持有车辆产权、提供融资并负责维护。他们管理着物理停车场、充电基础设施、车辆清洁及日常机械检修。

```
       ┌────────────────────────┐
       │  小马智行 (L4 技术栈)  │
       └───────────┬────────────┘
                   │ Gen-7 系统集成
                   ▼
┌──────────────┐ 路线调度 ┌──────────────┐
│  Uber App    ├───────────►│ 本地车队运营 │
│  (流量引擎)  │ 数据流交互 │  商 (Verne)  │
└──────────────┘            └──────────────┘
```

这种模式教科书般地体现了Uber首席执行官科斯罗萨西（Dara Khosrowshahi）倡导的“伙伴先行”策略。在发布“Uber Autonomous Solutions”时，他曾直言：*“自动驾驶的技术创新日新月异，但真正实现规模化商业落地需要更长的时间……通过这一方案，我们将这些艰难积累的核心能力赋能给合作伙伴。”*

通过将车辆的物理所有权转嫁给本地合作伙伴，小马智行和Uber得以将重度折旧挡在财报之外。此外，这种架构还巧妙地规避了监管壁垒：由本地合作伙伴而非跨国科技巨头直接对接地方市政当局，能更高效地拿到运营许可。

### 萨格勒布样板：Verne的务实妥协

整个扩张蓝图的起点位于克罗地亚萨格勒布。在这里，本地出行公司**Verne**（前身为Project 3 Mobility）充当了这一模式的雏形与试验田。Verne由Rimac集团首席执行官Mate Rimac创立，最初的愿景极具野心——试图打造一款完全自研、无方向盘的两座定制舱，实现垂直一体化的Robotaxi服务。

该项目曾顺利获得了**1.795亿欧元的欧盟“恢复与韧性基金”补贴**，但该资金附带了严苛的时间红线：项目必须在2026年3月31日前完成，后被延期至**2026年8月31日**这一最后限期。

由于自研底盘开发延误，且原本合作的Mobileye “Mobileye Drive”系统在短时间内无法实现成熟的商业化落地，Verne在2026年初做出了一个充满戏剧性却极其务实的决定：与Mobileye终止合作，搁置纯定制两座车的激进计划，转向引入小马智行的Gen-7 L4级系统，并搭载在现成的极狐阿尔法T5 SUV上。

这一变道让Verne得以赶在8月31日的红线前将车辆推上萨格勒布街头，保住了数亿欧元的欧盟补贴。交通出行行业分析师布拉德·坦普尔顿（Brad Templeton）在《福布斯》上对此评论称，这体现了Verne最初宣称的“从零自研”愿景与为了满足监管节点不得不引入第三方中国车型平台之间的无奈妥协。

萨格勒布试点积累的经验，目前正被应用于新锁定的四个欧洲核心城市。通过在前期配备“自动驾驶操作员”（安全员）进行试运行，Verne正在验证小马智行的本土化模型。这种渐进式策略有助于在全面切入全无人驾驶前，建立本地信任、绘制高精地图，并在人工监管下收集第一手路测数据。

### 技术瓶颈：欧洲城市路况的本土化阵痛

将L4级系统从凤凰城或旧金山这种宽敞的网格式路网，移植到欧洲紧凑多变的街道上，面临着截然不同的工程挑战：

* **高频机械振动**：欧洲历史悠久的城市中心充斥着高低不平的鹅卵石路面。这种路面产生的高频机械振动极易导致传感器（尤其是长距激光雷达和摄像头模组）的物理标定发生漂移。小马智行的感知软件必须利用实时动态标定算法，来即时补偿传感器发生的细微位移。
* **微型环岛与视觉遮挡**：相较于美国规整的路口，欧洲城市极度依赖多车道环岛和源自中世纪的狭窄巷道。这些场景存在严重的视觉盲区。车辆的运动规划系统必须表现出更具主动性的变道博弈能力，并能安全绕过经常阻断交通的行人和货车。
* **复杂骑行轨迹预测**：在阿姆斯特丹或柏林等自行车文化盛行的城市，非机动车流量极大且规律难寻。小马智行的路径规划算法必须能够准确预测骑行者身体的侧向晃动幅度，并在共享车道的狭窄空间内平顺跟车，避免因频繁触发盲目保护的“幽灵刹车”而毁掉乘客的乘车体验。

### 业界争论：商业故事VS现实落地

在Reddit的r/SelfDrivingCars等自动驾驶专业讨论版块上，2000辆的宏大目标遭遇了业内人士与极客们的质疑。

不少网友指出，2000辆更像是一个“长期意向”，而非短期内的实际落地规模。一位高赞评论写道：*“宣布2000辆听起来像个不错的公关新闻稿，但我们还是先看看他们能不能在萨格勒布真正跑通50辆全无人驾驶车辆吧。毕竟，萨格勒布现在车里还坐着安全员呢。”*

行业观察者也将这种混合模式与竞对进行了对比：
* **Waymo**：依然坚守重资产的垂直一体化模式，在全无人商业化上显得更加谨慎。尽管Waymo已开始在凤凰城和奥斯汀接入Uber平台，但它对定制的捷豹I-Pace及极氪（Zeekr）车队拥有绝对的运营控制权。
* **文远知行（WeRide）**：同样在推进国际化（已拿到阿联酋和新加坡的牌照）并与Uber合作，但其海外扩张往往更依赖当地政府的公共资源投入，而非Verne这类私营财团。

此外，舆论普遍认为Verne改用标准的极狐SUV，彻底打破了Mate Rimac当初承诺的“轮子上的移动生活舱”概念。就目前而言，商业化落地的现实重压迫使各方不得不向现实妥协：一款搭载中国L4级软件的标配电动SUV，暂时替代了欧洲本土高端定制自动驾驶的梦想。

### 结语：“三方游戏”能否真正走通？

小马智行与Uber的联手，在商业架构上无疑是一次聪明的财务腾挪。它让小马智行得以输出软件算法，让Uber锁定了平台佣金，同时把车队运维的繁重开销留给了本地伙伴。然而，欧洲复杂的路网结构和碎片化的牌照合规法律，预示着这场出海战役注定是缓慢且区域化的，并且在初期阶段将严重依赖人类安全员。萨格勒布仅仅是一个技术与合规的试验沙盒，接下来的四座欧洲城市，才能真正检验这种“轻资产”模式是具备可复制性的行业解药，还是仅仅是一场为了迎合政府补贴而攒出来的本土化秀场。
