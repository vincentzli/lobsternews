# 物理AI的十亿美金硬核现实：拆解软银2亿美元豪赌Gravis Robotics的底层逻辑

过去三年里，全球风险投资界的目光几乎完全被生成式AI所吸引——那些写文案、写代码、画图的虚拟模型消耗了数以百亿计的资金。然而在喧嚣背后，一场资本密度更高、赌注也更为惊人的暗战正在悄然铺开：那就是对物理世界的自主化改造。

没有任何一个行业能像建筑业这样，如此极致地展现出这场物理转型中的摩擦、前景以及令人望而生畏的工程复杂度。这首当其冲是一个深陷长期性、生存级劳动力危机的行业。行业数据显示，仅美国建筑业在2026年就面临近50万的人口缺口，且现有的劳动力中有超过40%将在2031年前退休。与此相伴的是，全球建筑业的生产力数十年来停滞不前，仅为制造业的一半左右。

就在这一背景下，**Gravis Robotics** 闪亮登场。这家总部位于苏黎世的初创公司成立于2022年，孵化自享誉全球的苏黎世联邦理工学院（ETH Zurich）机器人系统实验室（Robotic Systems Lab）。近日，该公司宣布完成了由软银集团（SoftBank Group）领投的2亿美元A轮融资。此轮融资将Gravis的估值直接推上了10亿美元的高位，使其瞬间成为欧洲最新晋的机器人独角兽。

这笔交易无疑是对Gravis核心技术路线的强力背书：其核心产品 **Gravis Rack** 是一种模块化的车顶安装式软硬件系统，能够直接“外挂”改装现有的标准重型机械（如挖掘机、装载机和推土机），将其瞬间升级为具备完全自主作业能力的智能资产。

然而，随着软银将数亿美元砸向这一赛道，也彻底揭开了工业机器人领域长期存在的一道分歧：我们究竟应该从零开始构建自主重型机械，还是说“后装改造”（Retrofitting）才是唯一具备商业可行性的现实路径？

### 路线之争：后装改造 vs. 从零重构

Gravis战略背后的核心逻辑，也是Built Robotics（Exosystem的开发者）和SafeAI等竞争对手的共识：重型机械的物理结构早已是一个“被解决”的工程问题。

“我们很早就意识到，重型机械在机械层面上已经臻于完美。”Built Robotics首席执行官诺亚·里迪-坎贝尔（Noah Ready-Campbell）指出，“卡特彼勒（Caterpillar）和约翰迪尔（John Deere）花了一个世纪的时间，才把这些钢铁巨兽打磨得如此皮实耐用。既然只需装上一个‘自主大脑’就能解决问题，为什么还要去重新造一台挖掘机呢？”

从商业逻辑来看，后装改造确实有着无可比拟的优势。对于承包商而言，替换一整支挖掘机车队意味着天文数字般的资本开支（CAPEX）——一台挖掘机的价格在15万到100万美元不等，设计寿命更是超过1万小时。后装改装则保留了这些宝贵资产，操作人员只需把像Gravis Rack这样的系统螺栓固定在车顶，接入机器内部的CAN总线（Controller Area Network），便能即刻获得自主作业能力。

然而，“从零重构派”——包括小松（Komatsu）和沃尔沃（Volvo）等大型主机厂（OEM）的研发部门——则针锋相对地指出，后装改造本质上存在技术天花板。传统工程机械在机械设计上完全是围绕“人机交互”展开的。它们的液压阀是为手动操纵杆优化的，驾驶室限制了传感器的最佳排布，且其电气架构缺乏真正实现故障安全（Fail-safe）自主性所必需的硬件级冗余。相反，一台从零构建的自主挖掘机可以彻底取消驾驶室，重新优化重量分配，降低重心，并原生集成线控液压阀组和高带宽的冗余布线。

### 控制闭环的本质：本体感受 vs. 外部感受

要理解为什么自动化一台挖掘机比让汽车自动驾驶难得多，就必须深入剖析其控制闭环。自动驾驶汽车主要处理的是“外部感受”（Exteroception），即感知外部环境（车道线、行人、交通标志）并在其中导航，车辆与路面的物理交互在绝大多数情况下是恒定且可预测的。

但挖掘机截然不同，它时刻都在与一个极其不可预测的地下介质——土壤——进行着超高强度的物理交互。

“传统的机器人技术过度依赖外部的视觉感知。”Gravis Robotics联合创始人兼首席技术官多米尼克·朱德博士（Dr. Dominic Jud）解释道，“但挖掘机不能只靠眼睛看，它必须去‘感受’泥土。通过将高频的‘本体感受’遥测数据（如液压缸压力、发动机负荷）与3D激光雷达数据深度融合，我们跨越了纯视觉模型无法逾越的物理鸿沟。”

```
                 +---------------------------------------------+
                 |                 Gravis Rack                 |
                 |  - 激光雷达/摄像头    - 边缘计算 (Orin)     |
                 |  - RTK-GNSS           - 路径规划 (SDF)      |
                 +----------------------+----------------------+
                                        | 控制指令
                                        v
                 +---------------------------------------------+
                 |                 底层控制                    |
                 |  - 电比例阀 (EPPV)                          |
                 |  - CAN 总线拦截 (J1939)                     |
                 +----------------------+----------------------+
                                        | 液压动力
                                        v
                 +---------------------------------------------+
                 |                 物理机械                    |
                 |  - 铲斗受力           - 关节位移            |
                 |  - 土壤动力学         - 发动机转速负荷      |
                 +----------------------+----------------------+
                                        | 本体感受反馈
                                        +----------------------+
```

Gravis的控制架构运行在一个多层闭环系统之上：

1. **外部感知建图与路径规划：** Gravis Rack利用固态激光雷达和摄像头，实时构建局部地形的三维带符号距离场（SDF）。系统会将该实时地图与通过“The Slate”操作平板导入的数字化建筑信息模型（BIM）文件进行比对。上层路径规划器则采用优化的采样算法（如RRT*），为动臂、斗杆和铲斗计算出无碰撞的作业轨迹。
2. **本体感受控制与力反馈：** 当铲斗切入土体时，系统会遭遇高度非线性的阻力。为了防止机器失速或翻车，Gravis引入了自适应导纳控制环路。液压缸缸体上的压力传感器能精准测量阻力。一旦铲斗撞击到埋藏的巨石，系统会瞬间实时调整轨迹，选择绕过或避开障碍物，而非蛮力硬推。
3. **“Sim-to-Real”强化学习训练：** 鉴于泥土力学在数学上极难精确建模，Gravis引入了强化学习（RL）。控制算法在庞大的虚拟仿真环境中接受训练，利用“土方开挖基本方程”（FEE）来模拟泥土与铲斗之间的物理交互。RL代理能够根据发动机实时转速波动和液压降，动态调整液压缸的伸缩速度，从而复刻资深人类操作员的“手感”。

### 非结构化环境中的安全挑战

建筑工地是一个典型的混沌、高度非结构化的环境。这里堆积的土方不断位移，深沟纵横，扬尘漫天，更有不可预测的工人在其间穿梭。这给机器人的感知系统带来了极其严苛的挑战。

* **扬尘“幕帘”效应：** 挖掘作业会产生大量悬浮扬尘。传统的激光雷达在恶劣环境下极易失效，因为激光脉冲会被扬尘颗粒反射，从而误判为障碍物，导致机器频繁无故停机。Gravis的应对之策是将激光雷达与调频连续波（FMCW）雷达进行深度融合，后者能够轻易穿透尘雾；同时，配合软件过滤算法，通过评估点云反射强度来精准甄别实体坚石与漂浮的沙尘。
* **机械剧烈震动：** 挖掘时的冲击力以及柴油发动机自身的震动，会让传感器承受强烈的冲击，这会导致摄像头和激光雷达的标定在短时间内出现偏差。Gravis为此设计了加装阻尼器的坚固型传感器阵列，并引入实时软件标定程序，利用惯性测量单元（IMU）动态补偿高频的结构性抖动。
* **预期功能安全（SOTIF）：** 根据 ISO 19014 等标准，系统必须能够防范控制系统失效。但在自动驾驶工程机械中，还必须解决“预期功能安全”（SOTIF）问题——即确保在传感器和算法完全正常工作的情况下，AI不会因场景的歧义而引发安全事故（例如，在强阴影遮挡下，AI可能会将工人的反光背心误判为路锥，从而继续强行作业）。

### 软银的物理AI版图

想要洞悉软银对Gravis这笔2亿美元重注的深意，必须将视线移向其创始人孙正义所布下的更大战略棋局。孙正义早已公开将软银的愿景锚定在“走向物理世界的具身超级人工智能（ASI）”。

软银集团董事总经理坂田大（Dai Sakata）坦言：“物理AI（Physical AI）是软银布局下一阶段人工智能图景的核心。”

这绝非一次孤立的财务投资。2025年底，软银完成了对瑞士工业机器人巨头ABB机器人（ABB Robotics）高达53.75亿美元的巨额收购。通过将ABB庞大的工业版图，与软银在Skild AI（物理大模型）、思灵机器人（Agile Robots，划归在Robo HD控股公司旗下）以及此次对Gravis Robotics的投资相结合，软银正在构建一个全栈式的物理AI版图。其终极目标是整合Arm的计算芯片、具身智能大模型、工业机械臂以及重型自主操作系统，从而全面接管从仓储物流、智能制造到基础设施建设的自动化未来。

### 监管与责任归属的博弈

然而，尽管热钱涌入，该行业依然面临着严峻的结构性逆风。

首先是监管枷锁。在美国，职业安全与健康管理局（OSHA）依然执行着传统的安全标准（如29 CFR 1926 Subpart O），这些标准强制要求重型机械的驾驶座上必须有合格的人类操作员。目前，在开放式工地上，完全无人驾驶的自主作业并没有明确的联邦法规通道。为了合规，承包商不得不划定极其严格的电子围栏隔离区，将人类与自主机械完全隔开——这一限制大大降低了工地现场的协同效率。

第二大阻碍是法律责任的划分。如果一台30吨重的自主挖掘机不慎挖断了高压天然气管道，责任该由谁承担？是工地的现场总包商？制造底盘的主机厂？还是设计路径规划软件的Gravis？

由于自主控制系统必须符合极其严苛的功能安全标准（如 ISO 13849 的 Performance Level d/e 级，以及 ISO 19014 的 Machine Performance Level 级），其软件可靠性要求比普通的标准企业级SaaS高出好几个数量级。在物理世界中，一次软件崩溃带来的绝不仅仅是“数据库损坏”，而是重达数吨的钢铁巨兽在失控下狂舞。

此外，劳动力流失的担忧也是不可忽视的阻力点。国际操作工程师工会（IUOE）等劳工组织坚称，激进的自动化技术正在威胁操作员的生计；而技术拥趸则反驳称，自动化只是在填补严重的用工荒，否则劳动力短缺将彻底拖垮全球基础设施建设的进程。

归根结底，Gravis Robotics代表了一次豪赌：重工业的未来，将不再由那些作壁上观的传统主机厂书写，而是由具备“改造既有世界”能力的软件优先初创公司来主导。手握2亿美元的新增资金，背靠软银的物理AI帝国，Gravis已经站在了风口浪尖，即将向世人证明：AI是否真的能够征服这片沾满泥泞的现实世界。
